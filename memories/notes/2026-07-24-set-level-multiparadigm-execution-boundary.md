# Set-level multiparadigm execution boundary

The user redirected the dense-enumeration successor away from the stopped
strict-composite `8/2,004` design and authorized preparation of a broader
set-aligned research round, subject to one final route approval before any
implementation or launch. The original task remains the governing goal:

```text
image plus the original `list all objects` prompt
  -> one autoregressive completion
  -> a larger clean-greedy final unique physical-owner set
```

A selected owner appearing while another ordinary Source owner disappears is
owner actuation or exchange, not success. The next round must seek a net gain
in the trusted final unique-owner set. A capability result may still have
retention or safety defects, but it must expand the single-completion set rather
than merely substitute identities. A usable improvement additionally preserves
Source owners, geometry, precision, valid rows, and natural stopping.

The external one-row-at-a-time prompt, explicit textual covered-set prompt, and
controller-assisted generation branch is retained as a possible future
diagnostic or teacher but is `pending`. It changes the input and generation
contract and does not enter the immediate route. Any future success on that
branch must be reported as controller-assisted and must ultimately transfer
back to the original one-prompt, one-completion task before it can satisfy the
program goal.

The proposed immediate route has one shared data step and four non-exclusive
training paradigms:

1. materialize trusted prefix-level owner events across the existing 2,004-image,
   34,068-trajectory training artifact rather than requiring every signal image
   to satisfy the census's natural-alias strict-composite predicate;
2. test a local owner-conditioned candidate loss that raises one trusted
   uncovered owner relative to confirmed duplicate, premature stop, or invalid
   actions while leaving other valid uncovered owners and unresolved rows out
   of the labeled denominator;
3. test exact-prefix useful-versus-harmful complete-row pairwise training;
4. test a genuine on-policy final-set utility objective from full completions,
   without presenting frozen-pool weighted cross-entropy as expected-utility
   optimization; and
5. test the local-plus-on-policy hybrid when both components pass their
   implementation and gradient checks.

The same original prompt and output schema remain mandatory for all four main
paradigms. Frozen Source, ordinary row cross-entropy, and Source-preservation
controls remain separate comparison surfaces. Unknown or ambiguous rows stay
neutral until resolved. The user permits targeted train-only visual
adjudication when it unlocks conclusion-bearing events; development and
held-out examples must not supply gradient labels.

Compute cost is not an early selection criterion. Do not require equal floating-
point operations, rollout counts, wall time, or remaining row/token budget
across paradigms. A finite generation cap remains a runtime safety boundary,
and used/remaining length remains a logged explanatory variable, but it is not
a universal event-admission requirement. Matched controls are retained for
causal interpretation rather than cost competition. If several paradigms work,
keep all of them until later evidence makes efficiency worth comparing.

The user explicitly permits unattended use of otherwise idle nightly graphics-
processing units. After final route approval, every semantically valid arm may
proceed through preparation and a short real smoke. An arm is promising enough
for an isolated overnight long run only when event supply is not confined to a
single image or row-zero corner, its real shared-parameter gradients have the
intended target-versus-harm direction without systematic Source/non-target
collapse, and the short smoke shows clean-greedy net owner gain over frozen
Source or its matched control that is not explained only by longer output or a
duplicate/invalid burst. Run every arm that passes; do not choose one because it
is cheaper. Preserve independent output roots and useful dose checkpoints.

The authorized research round stops after comparative clean-greedy evaluation
and discussion. It does not automatically promote a 256-image screen, a final
architecture, an external controller, or an internal coverage memory. Before
execution, create one concise formal research unit and route the live compass
and experiment index to that unit. This memory note is continuity only and is
not the live route owner.
