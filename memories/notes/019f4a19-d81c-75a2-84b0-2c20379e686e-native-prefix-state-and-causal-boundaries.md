# Native Prefix State: What Is Supported, What Is Not

Source session: 019f4a19-d81c-75a2-84b0-2c20379e686e, principally Jul 13 to Jul 19 2026.

## Compact conclusion

The Qwen3-VL decoder has a causally active, geometry-sensitive prefix state.
It can expose competing valid object modes, accept coherent phrase-geometry
events, redirect later routes, and in bounded cases suppress or switch a
physical owner. The evidence does not establish a stable, order-free
covered-object ledger, a universal latest-row carrier, a complete object
representation, or a selected final architecture.

## Fixed-state support and coherent events

At image 12576 prefix state 56, low-temperature sampling exposed a pizza route
that greedy missed and a competing left-cup route. A description token could
carry a coherent whole row once selected. A phrase-geometry factorial showed
that only the coherent cup plus left-cup geometry condition advanced to right
cup; phrase alone and geometry alone did not.

This supports an accepted phrase-and-geometry event gate. It does not decide
whether the gate is visual commitment, a geometry-sorted text transition, or a
hybrid. Local post-vision feature replacement and raw committed-box pixel
replacement were both null in that exact successor state. The correct negative
claim is narrow: the tested local committed-object revalidation surface was not
necessary there. It is not a claim that vision is irrelevant.

## Numerical and routing boundaries

Physical batch shape produced a dramatic bfloat16 white-bowl to orange-bowl
coordinate split in one case. Full-model float32 removed the relevant layout
dependence, and visual feature replay localized that recipient's split after
get_image_features. Other selected bfloat16 first-action changes were
one-to-two source-pixel same-instance jitters removed by float32.

Consequences:

* do not promote an exact low-precision token split as intrinsic object state;
* conclusion-bearing owner/logit work needs the stated precision and physical
  batch semantics;
* a rare broad counterexample remains worthy of isolation, but does not make
  every coordinate difference a new object choice.

Fixed-encoding hard spatial eligibility established a real regional routing
seam. The hard intervention could produce a full semantic-plus-geometry switch
on one anchor and geometry changes on others. Finite soft bias did not cross an
owner basin, and hard effects were mainly competing-row suppression. Later
query-time factorials made the same point: direct row reads can route
geometry, but the selected semantic effect depended on a broader, asymmetric
trajectory and was not a clean instance pointer.

## Residual and coordinate evidence

A layer-23 paired wine-glass state at image 7818 switched a donor-owned
geometry continuation with high donor overlap. The effect concentrated at x1,
and a layer-13 control did not pass. This is the strongest residual result:
one-way first-coordinate geometry-basin portability in one controlled case.
It is not a transferable four-coordinate object file.

Forced coordinate/box studies also found that early coordinates can strongly
constrain later boundaries. They failed to show that an early coordinate
universally names a physical instance. Common-support failures, part-sized
extents, and same-class ambiguity were treated as exclusions rather than
retrofit into causal claims.

## Natural rows, path dependence, and covered-set limits

Natural rows can redirect later outcomes:

* a nested bowl-carrot pair showed reciprocal successor changes;
* appending a person B at image 2299 strongly suppressed B and raised several
  other person variants, mainly at x1;
* a local same-covered-set control showed one covered-owner suppression case;
* sampled coordinate history could unlock later routes.

But these results coexist with severe route sensitivity:

* same physical covered set and same final row can yield different future
  owner sets under different earlier order;
* image 19109 re-emitted an earlier covered motorcycle under some orders;
* image 7816 gave one safe final unique-owner gain, while other causal
  interventions exchanged owners;
* image 12576 needed joint history from two earlier rows.

Use this language:

    prefix state is executable but fragile route state.

Do not use:

    the model has an order-free covered-set ledger.

## Training implication

Full-row likelihood does not reliably predict the free greedy branch. The
earliest differentiating token is usually the operative decision. A complete
row or coordinate history can be a mechanism probe, but it becomes a training
target only after a safe final-set value check. Neither generic coordinate
labels nor sampled-row novelty are approved targets by this evidence alone.
