## Result

The `training_set_completion` code package and its catch-all README are retired.
Retained implementations now have five owners: route learning, recurrence
dynamics, readout geometry, coordinate representation and visual grounding.
The five families have no executable import of another experiment family;
concrete model profiles are an explicit shared support owner. Existing older
DoRA/native/parallel/successor scientific profile relationships remain, rather
than being falsely described as universal utilities or fully independent packages.

Base code does not import probes or scripts. Shared native prefix extension,
inference-only row scoring, token/character boundaries, numerical recurrence,
saved-row accounting, JSON identity and immutable adapter-path replacement have
named owners. Different companion padding/EOS policies, tied/untied composition,
class versus geometry accounting and publication/encoding contracts remain
distinct. No generic trainer, experiment DSL, scheduler or runtime registry was
introduced. Re-export detours no longer force new families to import other
experiments' runners.

## Knowledge and provenance boundary

The live knowledge checker no longer needs a historic migration inventory to
validate a new unit. Document path routing belongs to tools, not src.artifacts.
The old checker command is a thin CLI. Full historical intake/exposure checking
remains an explicit extra operation.

Original closed-unit Markdown source links are not rewritten to current code.
If a cited source is absent, the checker can verify the unchanged document and
regular source blob at that document's last Git commit. It reports
`historical-source`, `exists:false`, commit and digest separately from live
links. That is document-version reference evidence, not an executed-code
certificate or receipt recovery. Edited documents, current routers, symlinks,
unknown missing source and missing data do not receive this fallback. No archived
source library or executable old-path alias was recreated.
