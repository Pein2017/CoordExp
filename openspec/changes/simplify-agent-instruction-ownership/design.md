## Decisions

### One constitution, thin project routing

`.codex/AGENTS.md` owns user authority, shared-environment constraints, research epistemology, high-risk validation/evidence integrity, user model-routing preferences and delegated acceptance boundaries. Tool invocation tutorials belong to the current harness contract. Worker mechanics belong to the native-team skill, not permanent context.

Each canonical Project gets a thin entry naming its responsibility and a few conditional owners. Keep a read-if-missing constitution pointer for other harnesses. Configure the existing Runner instruction facility to inject the same physical constitution once and verify live deduplication in all three Projects. No copied constitutions, symlink workaround or blanket trust relaxation. A pointer alone is not automatic loading.

### Content owners, not a second directory

Cross-checkout responsibility: main `docs/BRANCH_AND_WORKTREE_POLICY.md`. Shared retention and recovery: main storage policy, with local output routing. Research placement, catalog and current-source qualification: canonical `research/CONVENTIONS.md`. Model-specific execution: source/spec/tests and Qwen execution references. Move only genuinely shared instruction-maintenance and local runtime routing into the existing `docs/AGENT_INDEX.md`, not a new policy catalog.

### Skills

Delete codebase-design, reclaim-code-entropy, scope-economy-review and handoff packages after checking current references and preserved non-generic boundaries. Git history is recovery. Keep audit-review as the common review procedure; keep model-innovation-risk-audit as a small discoverable scientific-fidelity entry to its retained references. Keep specialized infer/eval, provenance, visualization, Qwen execution, runtime performance, smoke, accounting, session migration, research and worker transport resources. Compress research-flow by pointing to its existing research contract rather than repeating it. Native-team owns briefs, scoped repair/continuation, handoff and acceptance mechanics; persistent transport remains lead-worker. Keep all 12 external OpenSpec skills byte-identical. Preserve native/system/synced packages and the shared-memory external owner.

### Shared memory approval

The user's 2026-10-05 ruling allows proactive source-linked candidate capture through the experimental self-built shared-memory MCP. The main agent/designated consolidator reviews evidence before publication or supersession. Capture is not scientific acceptance and cannot change a user-owned research decision. The store's own skill owns caller identity and lifecycle. Remove research-flow's conflicting blanket explicit-request requirement, but do not apply this grant to Codex automatic memories or unrelated stores.

### Preserve scientific and runtime doctrine

Keep natural versus forced/teacher-forced evidence, nested populations and denominators, technical-invalid versus scientific-null outcomes, unknown/unmatched meaning, evaluator-feedback limits on raw-run reuse, sealed receipt integrity, real downstream validation and measured scaling bounds. Keep source-qualified research execution distinct from routine code/docs checks. Retain existing mechanism-promotion thresholds rather than silently changing science during cleanup.

## Risks / Trade-offs

- Missing constitution in worktrees: fix actual injection, not just prose; live load verification is required.
- Duplicate Runner/project load: inspect current implementation and then actual returned sources; do not count shortened duplicate copies as success.
- Discovery diagnostics: preserve symlink rejection and managed collection ownership; report remaining integration limits rather than manufacture valid fake packages.
- Global model preferences apply across harnesses: retain user choices, resolve actual model/tool support at use time.
- Concurrent edits: use current Git/path checks and guarded file revisions; inspect exact final changes.
- Reducing instructions does not prove agent behavioral equivalence: validate ownership, references and loading, and state the remaining behavioral uncertainty.
