## Deterministic manifest generation

The large TSV was generated by a one-off Python stream over the two frozen globs, writing only `manifest.tsv` under this package. The generator:

1. Parses `session_meta` and `response_item` JSON objects line by line, tolerating malformed lines while retaining the source row.
2. Extracts the latest actual user task after excluding whole standalone AGENTS/environment/permissions/skills/plugin/app-context bootstrap messages. It removes `<skill>...</skill>` and `<subagent_notification>...</subagent_notification>` blocks from genuine task messages. Assistant text is not used to invent research claims.
3. Uses raw metadata for source ID, cwd, parent thread, date, and absolute path. A child uses `parent_thread_id` as `root_or_group_id`; a root uses its own ID.
4. Classifies `high` for direct research questions, experiments, mechanism/model-behavior diagnosis, evidence or artifact interpretation, data statistics, or route decisions; `medium` only when a technical review can validate or invalidate research artifact validity, provenance, reproducibility, metric/evaluation semantics, or conditioning; `skip` for generic git sync, plugin/tooling, agent/session management, ordinary implementation, and ordinary code/spec review without material research influence.
5. Assigns `duplicate` only for repeated normalized task payloads after the first row. Every physical source retains its own row. Normalization collapses whitespace, long hexadecimal IDs, and absolute path spellings only for duplicate detection.
6. Derives compact topic, evidence-surface, and lifecycle labels from the sanitized task text. These labels are routing aids, not scientific evidence.

No dependency installation or network access was used. The generator command was a here-document Python invocation with stdout redirected to this package's `manifest.tsv`; the post-generation verifier counted rows, checked allowed values, checked May/June totals, and verified every path exists.

## Limits

- Hidden reasoning is unavailable and was not inferred.
- A session result is provenance, not current authority; synthesis names current-owner gaps and does not promote implementation or mechanism claims.
- Residual heuristic boundary: using the latest actual user task can undercount an earlier research turn in a long session whose latest task is generic implementation/review. A review remains medium only when its raw task names an evidence, artifact, provenance, reproducibility, metric, evaluation, or conditioning validity surface. No hidden reasoning or assistant-derived intent bridges that boundary.
- No L2 worker was started: this session exposed no callable `gpt-5.6-luna` route. The L1 pass therefore owns the deterministic census and sample audit; this is a topology gap, not evidence that no independent review is needed.
