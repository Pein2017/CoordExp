# Ask Advisor

Use for an explicit consultation or when competing explanations, mathematics or
a consequential design choice could change direction or acceptance. Do not require
exhausting local attempts first; settle cheap factual questions locally. Primary
research handling follows [model routing](../../AGENTS.md#model-routing), not this
extra consultation. User-mediated web consultation uses [ask-pro](../ask-pro/SKILL.md).

Give one decision, objective/constraints, alternatives, verified observations,
strongest counterevidence, source identities/denominators and what the answer
would change. Separate interpretation from evidence and let the advisor challenge
the framing. Unsupplied or uninspected evidence remains unknown.

Use [native-team mechanics](../native-agent-team-guide/SKILL.md) for the actual
assignment and supported Astra model/effort. Prefer a self-contained fresh brief
when it supports independent framing; a separate context is not proof of
independent judgment. Reuse a suitable advisor for the same unresolved question.
Assign read-only inspection/reasoning, with no edits, experiments, additional
agents or launches. Use native completion, not an API wrapper or extra watcher.

Request a recommendation or NEEDS_CONTEXT/HOLD, decisive evidence, strongest
alternative, reversal condition and smallest discriminator. The lead checks
load-bearing claims and records the ruling at its existing owner. Advice is not
scientific evidence or user authorization. Reconsult only for a specific gap or
new evidence that can change the decision; no automatic second reviewer.
