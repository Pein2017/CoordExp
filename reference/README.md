# Retired source snapshots

The migration-time `retained-sources/objects/` corpus mixed source code,
configuration and Markdown snapshots. It is retired from Git and is not a
maintained code library or a source for future reruns.

Keep conclusions, useful process details and necessary hyperparameters with the
owning `research/experiments/<unit>/` record. Maintained code belongs in `src/`
or `probes/`. Local `runs/` captures belong to their current run receipts; this
cleanup does not remove them or alter active research.
