## Lane A: spatial progress gate

Frozen question: holding the covered owners and image fixed, does moving the
historical reference across a fixed N in lexicographic `(x1,y1)` order selectively
change N's preference in the direction predicted by a progression gate?

Motivating case only: tied14038 historical A is `[788,670,850,697]`, annotation A
is `[784,670,851,704]`, actual repeated A is `[795,670,850,697]`, and the retained
N x1 values are 782,783,785,786. Confirm these bindings. They are a hypothesis seed,
not permission to assume any hybrid extent preserves the owner. In image885 the
retained N candidates lie ahead of A; retain this as a counterexample stratum,
not an outcome-based exclusion. It need not qualify for a within-owner crossing.

For each admitted crossing, freeze at most five conditions:

1. Exact native history.
2. Owner-preserving reference before N.
3. Owner-preserving reference after N.
4-5. Matched non-order-changing extent controls, where admissible.

Prefer a symmetric pair around N (e.g. 784/788 around N=786), with all other
historical tokens unchanged and the edited box still credibly the same A.
Use equally sized changes in x2/y2 as sham controls where geometry permits.
For a y1 crossing, source and candidate x1 must be equal in both arms; y1 is not
the lexicographic key when x1 differs. Freeze at most one x1 and one y1 contrast
per boundary within the five-condition cap; if both cannot fit, prefer the
cleaner symmetric contrast by admission geometry, not outcome.

The primary directed contrast for each fixed N is
`logP(N | before) - logP(N | after)`, with the analogous conditional corner
contrast and individual A-row effects retained separately. H1 predicts positive
N effects for the crossed candidate and a directional structure absent from
non-order controls. Retain noncrossed candidates to check a generic score shift.
Do not infer a gate merely because A-N changes when A itself is edited/scored.

Reject/downgrade H1 if admitted symmetric crossings lack the predicted direction,
or changes track sham perturbations/proximity without ordering specificity.
An ordering effect in normal and failure states may show a general policy; a
burst-cause claim additionally needs a demonstrated natural reference error and
the predicted effect on actual owner selection. No dose/extent expansion after
seeing results. Absence of admissible crossings leaves H1 unidentified.

Frozen question: under a fixed native text history, do localized A and N visual

Save the response matrix for each frozen A and N realization:
`R[region,candidate] = logP(candidate | region ablated) - logP(candidate | native)`.
Also report A-N relative effects: selective A removal predicts a negative change;
selective N removal predicts a positive change. Include background effects and
ordinary same-category transitions, not just the failure state.

H2 predicts loss of correctly separated A/N visual dependence at affected states,
with both outputs responding to the same source or otherwise losing instance
specificity compared with interpretable controls. General degradation under all
masks, unqualified erasure, floor effects, or no demonstrated visual sensitivity
do not establish aliasing. Clear correctly separated dependence at failure
downgrades H2 even if greedy still repeats. Before/after-boundary comparisons are
observational; they do not isolate repeat count or training cause. Nonselectivity
already present earlier is consistent with upstream ambiguity; an effect emerging
only at later text states points more toward decoder access/state. Neither proves
vision-pretraining misalignment.
