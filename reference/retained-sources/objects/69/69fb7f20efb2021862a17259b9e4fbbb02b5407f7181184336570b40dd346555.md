# Recurrence distribution census

From the frozen natural output source population, which image/category, spatial,
size, sequence-phase and annotation-density proxies concentrate numerical
recurrence, and does the same distribution recur in a deterministic prospective
128-image cohort?

## Ownership and boundary

Lane A of the released `2026-09-19` parallel package. Root
`01a0a3d5-dc45-7693-8467-4801aa7190df` owns scientific acceptance and successor
decisions. This lane owns the CPU census, the prospective source selection, the
shared source/panel records, the original-policy natural readouts and their
reducers. It does not own intervention outcomes or the root integration tree.

The mature source is the accepted 145-unique-image, four-condition natural
package `2026-09-18-untied-highconfidence18-natural`. Its tied and
untied-plus-axis step-2444 bindings are reused as a package comparison. Existing
production val200 evidence, if qualified cheaply, is retained as a separate
runtime stratum and is never pooled silently.

## Frozen estimand and evidence

The primary descriptive unit is an image. For each image/model/policy/runtime
stratum report exact complete-row repeats, existing <=8-bin same-description
near-repeat rows, valid/invalid geometry, malformed rows, literal-invalid
repeats, onset position, longest exact run, excess rows, EOS/cap, endpoint
occupancy and category exposure. Pair counts remain separate from repeated-row
counts because a run of length `r` contributes quadratic all-pairs edges.

Category summaries include image exposure denominators (images emitting a
category and total sampled images). Output length, small-object/annotation
density proxies, crowd/group ambiguity and recurrence are separate quantities;
density derived from duplicated predictions is labelled endogenous. Saved
pre-burst annotation/context fields are imperfect proxies. Unknown and
unmatched rows are retained as unknown, never physical false positives.

The prospective cohort is selected from the actual processed-data manifest
before inspecting any new model output. The selection key is `(split, image_id,
file_name)` and the frozen rule is deterministic random sampling with seed 19
of exactly 128 eligible unique records after excluding prior train256, dev128,
fresh128/sentinel and high-confidence identities. No replacement is made for
difficulty or outcome. The cohort estimates this sampled eligible population,
not COCO generally.

The shared mechanism panel is frozen by rule before new intervention outcomes:
the existing earliest-run selector chooses the first qualifying exact triple
(otherwise first pairwise <=8-bin near triple), including invalid geometry;
metadata-only round-robin stratification is over source/model, predicted
category, coordinate region, box-size bin and sequence phase, with at most one
failure and one non-recurrent proxy per image/model. The caps are 24 original
policy failure boundaries and 24 non-recurrent proxy boundaries. Existing
qualified boundaries are carried with their native source/prefix/token/receipt
bindings; new-cohort cases are added only by the same frozen function. The
known val885, val5586, val7511, val14038, val632 and donut417044 boundaries are
included when their actual source binds; bird309264 is eligible only as a
non-recurrent control and is never forced into a failure stratum.

## Execution contract

New generation uses original-readout natural greedy only for tied-original and
untied-original, RP1, at most 256 outputs (128 images x 2 models), with the
qualified native cap3084 route. The output root and probe root are immutable
lane-owned surfaces. No training, optimizer, head/input change, rescue sweep,
checkpoint sweep, source annotation change, or outcome-driven replacement is
authorized. A source identity conflict holds new generation only and does not
invalidate the CPU census.

Before broad generation, qualify one real native group and read back its raw
tokens, source/prefix/image/model bindings and receipt. Stop at a bounded
technical failure, the declared output ceiling, or completion. Report actual
model calls, GPU-seconds, retained bytes, admitted/failed/analyzable image
denominators and ended processes.
