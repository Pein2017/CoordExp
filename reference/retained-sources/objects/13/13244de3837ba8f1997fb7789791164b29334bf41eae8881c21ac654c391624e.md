# Recurrence spatial source: visual position x history position

## Frozen question and boundary

For the same scene and the same recorded recurrent prefix, does the location
of a numerical recurrence follow the moved visual content, the moved coordinate
history, or a fixed coordinate/canvas preference? The primary comparison is a
free original-policy continuation from coherent `00` versus coherent `11`,
with every emitted box mapped back through the known affine transform. `10`
and `01` are mismatch diagnostics. They do not measure detection quality.

This unit consumes the shared mechanism panel after Lane A freezes it. The
mechanical qualification source is the immutable mature natural package
`2026-09-18-untied-highconfidence18-natural`, bound through the accepted
numerical-feedback selection records `tied-417044-failure` and
`untied-417044-failure`. The selected source row is included in the native
history prefix; free continuation begins at the next row boundary. The four
mature conditions remain separate strata. Tied versus untied is a package
comparison, and original versus normalized is reported separately; this lane
generates original-readout cells only.

The already executed 14-cell `417044` set is retained as pilot qualification
only. It does not satisfy the final Lane B denominator. The final run must
iterate the published shared panel through the CPU state entry, reuse a pilot
state only when its complete source binding is present, and leave all other
states pending until their exact source, prefix, and route bindings pass.

## Geometry frozen before outcomes

The source images are no-resize processor images with dimensions divisible by
the Qwen patch/grid factor. For every source image with width `W` and height
`H`, use one fixed pixel displacement `d=128` (four 32-pixel grid cells) and a
common canvas of `(W+2d, H)`. The source scene is copied byte-for-byte into the
canvas without resampling: the centered baseline is pasted at `x=d`, the
negative cell at `x=0`, and the positive cell at `x=2d`. The fill is a fixed
edge-independent constant recorded in the transform receipt. All seven cells
for a panel state use the same canvas dimensions, pixel scale, copy operation,
processor settings, image grid and text template. Since the source is copied
inside a larger canvas, no source pixels are clipped or lost.

For sign `s in {-1,+1}`, the visual/history translation in pixels is
`tau(s)=s*d` relative to the centered baseline. The normalized-coordinate map
is computed from exact canvas pixels and rounded once to integer bins with
round-half-even; it is never hand tuned. For a source-width range observed in
the mature panel, this moves the old and new windows by more than 8 bins in
each direction. Every history box is mapped with the same affine translation,
then checked for `[0,999]`, clipping, row order, and serialized token-count
preservation. Existing invalid source boxes remain in the history; their source
validity, mapped validity, order preservation, and any rounding-induced
validity change are recorded per row. A true out-of-canvas map, collision, or
token-count change holds that state before model work. The description strings,
row order, row count and serialized token count are otherwise unchanged.

The seven cells are `00`, `10-`, `10+`, `01-`, `01+`, `11-`, and `11+`:

* `00`: centered image and centered history (shared by both signs);
* `10s`: shifted image, centered history;
* `01s`: centered image, shifted history;
* `11s`: shifted image and history by the same sign.

The history is supplied only through the exact native prefix path. The image
cache is rebuilt for every cell; no old image cache or hidden state is copied.

## Admission and outcome rules

Before interpreting a transformed continuation, a centered `00` must enter the
same native route: it must retain at least one valid complete row and must not
show a parser/geometry failure caused by the canvas seam. For a failure source,
the mature failure predicate must persist in `00` (earliest exact run of at
least three, otherwise earliest same-description <=8-bin near run of at least
three, using the existing reducer). An existing-bank match is an optional
grounding witness, reported separately after mapping to source coordinates. A
zero witness limits physical-grounding claims but does not discard numerical
recurrence evidence. If the predicate disappears, or `00` loses all valid
grounding, the state is reported as admission-HOLD and no transform cells are
interpreted. A proxy is admitted with the same centered valid-row check and
explicitly recorded as non-recurrent under the frozen selector; proxies are
never promoted to failures after seeing transformed outputs.

All seven cells use original greedy RP1, temperature 0, top-p 1, no sampling,
and at most 32 complete rows / 512 new tokens / EOS. A supplied prefix row gets
no recovery credit. Outcomes retain exact/near recurrence, alternative
recurrence, valid/invalid/malformed rows, cap/EOS and coordinate occupancy.
Unknown predictions remain unknown. A physical-owner statement requires the
existing local witness; without it the result is numerical/trajectory evidence
only.

At the common row boundary, retain opener/EOS competition. With the identical
description/wrapper forced, capture full-vocabulary logits and log probabilities
for the old and mapped moved x1 windows, the full-vocabulary top competitors,
coordinate-family mass and the mapped coordinate-distribution shift. This is
conditional forced-description evidence, separate from free continuation.

## Cost and stop

Qualification uses one mature source state and at most one seven-cell set. The
final panel is capped at 48 states x 7 cells = 336 continuations, with only
proportionate parity controls. There is no transform search, padding tuning,
normalization rescue, bulk image review, training, checkpoint sweep, head or
embedding edit, or new scheduler. Stop locally at admission-HOLD if the
centered canvas loses grounding or the failure pattern; do not search another
transform. Record all excluded/no-longer-recurrent cases with source and
attempted denominators.
