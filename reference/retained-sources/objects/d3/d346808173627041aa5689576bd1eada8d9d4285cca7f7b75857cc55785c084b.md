# N256 preimplementation harness benchmark v1

## Frozen comparison

One identical read-only package audited the N256 handoff, Human13 precedent,
and frozen G0 cohort at HEAD `0dc1dfc7b4fd793c1b51505f6c1375c99aab4b2e`.
The matched leaf routes used GPT-5.6 Terra, `high` effort, depth 1, no writes,
no GPU/model execution, and the same two-part output contract: scientific
falsification plus implementation/verifier audit. Native depth 2 was an extra
topology probe, not part of the matched three-way ranking.

## Matched depth-1 result

| harness | wall time | provider-reported token fields | outcome | decision-bearing result |
|---|---:|---:|---|---|
| OpenCode | 136 s | 3,248 input + 61,952 cache-read + 1,606 output | `NEEDS_CONTEXT` | Recovered the row-manifest, nested-order, null/K, screen, and N2/N4 gates; fastest and smallest reported context. |
| Pi | 173 s | 106,481 input + 761,344 cache-read + 10,446 output | `NEEDS_CONTEXT` | Broadest live census and code-seam detail, but much heavier; its wording about evaluating the single N2 swap four times must not be read as four independent nulls. |
| Codex native | 178.219 s | 569,481 input including 495,360 cached + 7,252 output = 576,733 total | `HOLD` | Recovered the same blockers, attempt discipline, target-blindness boundary, and exact focused verifier; full native rollout and usage evidence were locally auditable. |

All three reached the same safe decision: do not launch before freezing the
fixed row identity, complete-route nulls, target-blind screen protocol, and
production-shaped N2/N4 resource gate. This is one task, so it supports routing
for this task shape only, not a general harness ranking. Provider token schemas
are not normalized, and dollar cost is unavailable for OpenCode/Pi.

## Native depth-2 topology probe

The native L1 delegated two independent L2 lanes (scientific policy and
implementation verifier) and integrated both successfully. End-to-end wall
time was 256.477 s. Offline native-ledger totals for the L1 plus both L2s were
2,826,703 measured tokens and an estimated USD 0.824671 under the local price
snapshot, versus 576,733 tokens and estimated USD 0.334338 for native depth 1.
That is about 1.44x wall time, 4.90x measured tokens, and 2.47x estimated cost,
without a new conclusion-changing blocker.

## Routing decision

- Use OpenCode leaf for the cheapest first-pass read-only audit of this shape.
- Use Codex native when durable local provenance, native delegation, or
  decision-grade acceptance evidence owns the choice.
- Do not use native depth 2 for this narrow audit unless the two independent
  outputs will change a material decision.
- Pi remains useful when exhaustive live source traversal is worth its larger
  context footprint; it was not the efficient route here.
