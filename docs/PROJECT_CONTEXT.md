# Project context

CoordExp studies autoregressive coordinate-token detection/enumeration. The goal
is distinct physical-owner coverage with explicit output debt, not only a teacher
likelihood or a geometry benchmark. Current scientific interpretation is owned
by [research/index.md](../research/index.md) and its eight questions.

The canonical research checkout is `/data/CoordExp/.worktrees/research-probes`.
The production base `/data/CoordExp` and infrastructure worktree remain distinct;
cleanup of research does not authorize changes to those working trees.
Core code is shared through explicit imports, not sibling-worktree execution.

Only maintained capabilities remain in HEAD. Exact past protocols, implementations
and stages use the catalog's Git recovery context. Historical inspection does not
qualify continuation; explicit current source identity is required for new runs.
