# A2 Prefix/Sampling Manual Audit Packet

Scope: completed A2 val200 cells from `three_checkpoint_prefix_sampling_sweep_20260514`.

Primary files:
- `audit_queue.csv`: ranked first-pass manual audit queue (48 images).
- `audit_queue.jsonl`: same queue with numeric signals.
- `*_raw_selected.jsonl` and `*_guarded_selected.jsonl`: selected records in identical order for rendering/comparison.

Recommended labels per audited object or image:
- `true_duplicate`: same object repeated; guard/suppression is desirable.
- `distinct_valid_object`: separate object; guard/suppression is too aggressive.
- `valid_unlabeled_or_lvis_reference`: visually real object missing from COCO labels; should inform LVIS/objectness direction.
- `wrong_semantics`: object exists but category/description binding is wrong.
- `bad_box_or_boundary`: semantic target plausible but box is too loose/tight/shifted/truncated.
- `hallucination_background`: no visible object; should count as true FP.
- `under_emit_missed_valid`: visible object omitted by model.

Start with buckets in this order: guard_hurts_possible_valid_object, guard_helps_likely_duplicate, sampling_improves_valid_object_emission, sampling_hurts_or_injects_noise, rp105_duplicate_or_stability_regression, under_emit_high_fn_dense_scene.
