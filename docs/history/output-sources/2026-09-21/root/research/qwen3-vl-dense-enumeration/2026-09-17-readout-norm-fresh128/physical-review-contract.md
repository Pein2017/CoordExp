# Blinded bidirectional physical-difference review

Review only the assigned fresh cohort images. Policies A/B are blinded per image; do not read the blinding key or known gain/loss table. Inspect the original image plus ALL packet pages for both policies; additional crops use only that image, not new detector/labels. Identical literal rows are collapsed with multiplicity preserved; near overlaps still need identity judgment.

For each image save image_id, viewed_paths, and correspondence_groups. Each group contains A_ids/B_ids (A1 etc refer one-based unique_rows indexes, not generated row numbers), a concrete visible entity description, and verdict: shared_owner, A_only_owner, B_only_owner, false_instance, geometry_or_granularity_uncertain, identity_uncertain, or invalid_extent_unresolved. Group multiple rows denoting the SAME physical entity; touching/overlapping boxes alone do not prove identity. Every unique row in both policies must appear exactly once in the grouping; use unresolved for any uninspected/unclear rows. Empty lists on one side imply exclusive owner credit only when visually confirmed that the other policy has no corresponding valid representation. A row near the object but different IoU can still refer to that owner; separate localization/extent errors. Full-scene/part/group boxes do not automatically count as atomic owners. Ground conclusions in visible evidence and row IDs, not class strings alone. Border coordinates are legal.

Summarize confirmed A-only/B-only independent owners, false-instance differences where established, repeat/geometry/granularity notes, and ambiguity. UNKNOWN annotations are never automatically FP. This is bounded model-assisted review, not verified new GT or a scene census. If no complete physical net estimate is defensible, say so; preserve confirmed directional witnesses and unresolved competing groups. Do not fabricate a numeric exhaustive count from unreviewed outputs. Do not modify banks/source/checkpoints. Stop after the assigned images; no review recursion.
