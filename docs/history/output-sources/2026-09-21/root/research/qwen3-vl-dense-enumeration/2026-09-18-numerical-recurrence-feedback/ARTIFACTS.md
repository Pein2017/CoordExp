# Numerical recurrence feedback artifact map

Candidate evidence only; root owns independent scientific acceptance.

- `panel.json`, `estimands.json`, `selection.json`: seven fixed targets, preserved native companion groups, deterministic episode/healthy selection and pre-outcome estimands. The panel was extended with completed new-source bindings before replacements; model/input/group constants stayed fixed after `input-correction.json`.
- `runtime/{model-policy}/val-extra/{raw,trace,receipt}.json`: twelve new target outputs. Other sixteen compatible target outputs are hash-bound via panel saved_sources; companions retain their original generation identity and are not additional target cases.
- `candidate-manifest-{untied,tied}.json`: exact source rows, role positions, native-score-selected replacement bins, rank/distance/validity/order flags and source-capture bindings, frozen before paired releases.
- `source-capture/` or paths bound by those manifests: declared full-vocabulary competition, all1000 coordinate scores, final head inputs and complete fixed-suffix likelihood. Read exact paths from the manifests rather than infer by directory names.
- `coordination/paired-scaleout-plan-v1.json`, `paired-scaleout-v1.json`:276 jobs, commands, receipts, exits, timings and bounds. Four GPUs were used concurrently, despite eight authorized; no operational constraint is documented. This was underutilization by the implementation owner, not a reason to rerun.
- Per-job `paired.json`, `paired-replay.pt`, `release.json`, `receipt.json`: paired native/changed head states and coordinate deltas, shadow equal-norm scores, full fixed-suffix token probabilities, all target/companion tokens and stopping reasons. All free-release analysis is target-only; companion continuations are uninterpretable, including116 warning-bearing releases with padded companions. No all-layer KV or attention archive.
- `runtime/pilot-runtime-v2/baseline-native-untied-original/`: one actual native/no-op qualification. Its288 free target tokens match the saved original suffix exactly. Other native baselines reuse saved original suffixes; they are not25 independently regenerated baselines.
- `reduction.json`, `reduction-recheck.json`: JSON-exact independent saved-artifact replay. Includes all candidate log probabilities, per-image/model/episode K summaries, free-return/repeat/invalid/EOS metrics and reused native baselines. Source control `baseline_mode=native_noop` is excluded from K scientific counts; its copied selection metadata is not used to infer rank/order effect.
- `readout-accounting.json`: optional CPU-only common/centered decomposition over the predecessor442 captures; no new inference operator.
- `failed-input-v1/`: four pre-forward input failures, old panel and producer. `pilot-runtime/`: zero-forward source lookup failure. No failure is recast as a scientific null.
- `sources/`, `verification.json`: exact executed source mapping, source-selection and candidate reconstruction, cost/job closure. No prior model/data/annotation changes.
- `result.json`, research owning `results.md`/`state.json`: integrated candidate interpretation. `integrated-terminal.json` is final integration; original child `coordination/settlement.json` and `runtime-child-settlement.json` are retained runtime-only receipts.

Reproduce from repository cwd:

```bash
PYTHONPATH=. python probes/training_set_completion/numerical_feedback/reduce.py --output /tmp/numerical-feedback-reduction.json
PYTHONPATH=. python probes/training_set_completion/numerical_feedback/readout_accounting.py
```

No physical-owner review census, gradient/operator update, parameter training, or successor is performed. UNKNOWN remains UNKNOWN. Candidate counts and correlated slots are not population rates.
