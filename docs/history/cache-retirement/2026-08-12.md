# Obsolete cache retirement — 2026-08-12

This receipt records an explicitly authorized, irreversible removal of
disposable cache payloads. It preserves identity and scope, not the removed
payload bytes. Historical results and their immutable artifacts remain, but a
checkpoint that depended on one of these old cache payloads can no longer use
that payload for exact continuation.

## Preconditions observed

- Fixed checkout: `/data/CoordExp/.worktrees/CoordExp-swift` at
  `8fb282d3b5c10fb0847cc54fee331b191ab90cd4` before this documentation change.
- No active `src.train`, `prepare_train_cache`, or vLLM process was visible.
- `lsof` reported no open file below the pack-cache root.
- No current config, run manifest, checkpoint, or receipt directly referenced
  the retired pack-cache fingerprints.
- No current repository reference to the retired vLLM materialization hashes
  was found. This is a bounded textual-reference check, not proof that the
  payloads never contributed to a historical result.

## Explicit exclusions

- all private/current v3 pack caches below `outputs/probes`, including Wave7
  exact-resume inputs and receipts;
- the currently referenced v4 vLLM materializations `2ae15bcc...` and
  `39df6dd7...`;
- every model weight, raw/processed dataset, run output, checkpoint,
  TensorBoard file, evaluation artifact, and research receipt.

Worktree-local `__pycache__`, `.pytest_cache`, and `.ruff_cache` directories are
ordinary regenerable scratch and were also eligible for removal; they carry no
research or resume claim.

## Outcome

- All 37 listed pack-cache payload directories and their obsolete zero-byte
  lock files were removed. The pack-cache root remains present and empty.
- The five listed vLLM materializations and their obsolete zero-byte lock
  files were removed. Two referenced v4 materializations remain; the
  materialization root measured about 12 GiB afterward.
- Fifty-nine worktree-local `__pycache__`, `.pytest_cache`, and `.ruff_cache`
  directories were removed; the post-cleanup residue count was zero.
- Removed payloads accounted for 86,189,897,360 observed bytes (about 80 GiB),
  excluding the negligible scratch-cache residue. This is an inventory sum,
  not a filesystem-wide free-space delta under concurrent host activity.
- The retained private v3 Wave7 cache still measured about 227 MiB after the
  cleanup.

The removed payloads were not moved to trash and are not directly recoverable.
They can only be regenerated by a compatible historical builder from their
original inputs; current readers intentionally provide no legacy decoder or
migration path.
