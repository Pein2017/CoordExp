# Current context

## Task, not an assumed mechanism

Compile verified object support and useful continuations into ordinary model parameters. From the original image and an empty assistant prefix, one natural greedy completion should cover the trusted physical owners without merely replacing misses with old-owner loss, repetition, invalid geometry or abnormal stopping. Sampling is a discovery instrument, not the deployment result. An explicit internal owner ledger is neither assumed nor established.

The current training-first task uses original GT plus independently admitted old/new physical owners. A cumulative stage must finish before adding images. Early held-out validation is deferred for this task; it must not become a new veto inherited from an older study. Generalization remains a later research obligation, not something the present fit establishes.

## Carry these constraints into discussion

Physical identity and category correctness are separate axes. A confirmed real owner with an uncertain class may carry geometry support without a fabricated class target. Unknown/unmatched is not negative. Direct CE masking removes a target contribution, not the token history or all downstream gradients. Old successful suffix evidence cannot be reused after silently deleting its conditioning rows.

Existing confirmed false-object debt may temporarily remain under the current task, but it must not be positively reinforced; newly introduced confirmed errors must be repaired before stage growth. Repeats, malformed rows, invalid geometry and caps have no such completion exemption. Intermediate training regressions were permitted; stage acceptance still requires the joint per-image outcome. See the linked protocol in the state file before changing any of these semantics.
