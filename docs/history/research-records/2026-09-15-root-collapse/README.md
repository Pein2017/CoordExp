# Research-tree consolidation

This is the short record of the 2026-09-15 research-tree migration. Current
conclusions, useful process details and necessary hyperparameters belong to
their owners under `research/experiments/`; the old taxonomy and migration
source snapshots are not execution authority.

On 2026-09-24, the copied source implementations and source-code hashes were
retired from Git. Exact historical code replay is no longer supported. The
path-only manifests remain for resolving moved research-document links; they do
not claim byte recovery.

The 106 frozen exposure JSON files remain at their original paths because
`probes/parallel_owner_research/transfer.py` reads them directly. Their data
identity and 135 image IDs remain protected independently of source-code
retention.
