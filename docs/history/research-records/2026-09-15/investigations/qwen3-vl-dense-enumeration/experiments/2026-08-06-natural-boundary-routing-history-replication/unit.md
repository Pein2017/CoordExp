## Owning question and decision boundary

On the production-relevant S `geo_sorted_xy` step-2444 substrate, using the
admitted 13-image, 392-owner panel and exact native natural prefixes:

1. does hard target-B-exclusive query-to-image routing reproduce strict target
   owner transcription beyond one A3 event;
2. can a single finite, context-preserving regional bias reproduce any part of
   that hard-oracle effect;
3. do latest-row history states causally control natural row admission, STOP,
   repeat/suppression, or uncovered-owner reallocation before an opener is
   injected; and
4. only after both handles are qualified, does a fixed static-by-history
   crossover change one-row or three-row outcomes; and
5. is the S evidence strong enough to propose, but not authorize, a concrete
   next production-training discriminator?

pre-opener boundary. Teacher-forced scores and post-opener releases are
diagnostics. A3 step-2445 may receive one minimal matched secondary probe only
after the S main matrix, and only to ask whether an S phenomenon is A3-specific
or whether the commit wrapper changes admission versus conditional selection.

recommendation. This unit performs no training, optimizer step, weight update, A2
run, wrapper or special-token change, production decode change, architecture

## Validity and outcome semantics

Mechanical validity and scientific qualification are separate fields.

A cell is mechanically valid when checkpoint/config/panel/prompt/wrapper,
exact prefix, token IDs, absolute positions/MRoPE, masks/hooks, tensor
shape/dtype/device, finite values, call counts, cleanup, and no-op receipts all
match. Wrong identities, retokenization, missing MRoPE, mask leakage to
undeclared keys, stale hooks, or an operator that does not actuate are technical
invalidity and receive one exact repair only.

Every release receipt carries a required, non-defaulting `admission_mode` with
value `pre_opener_natural` or `post_opener_seeded`, plus
`opener_generated_by_model`. A finalizer rejects a row lacking either field.
The legacy `natural` flag is not evidence of admission mode because old seeded
rows already used it. Cross-field validation is fail-closed:

- `pre_opener_natural` requires the initial prefix's last token to differ from
  the opener, no injected opener at any boundary, and
  `opener_generated_by_model=true` if and only if the first generated token is
  the opener. Natural STOP or invalid first tokens set it false.
- `post_opener_seeded` requires the supplied opener token and seed provenance,
  sets `opener_generated_by_model=false`, and is never eligible for a primary
  natural endpoint.

A new technical invalidity claim requires a persisted failure log with verbatim
stderr in the failing immutable run root. Lead-observed, unattested old causes
are historical context only and do not authorize this unit's one exact repair.

A parser-valid, native-wrapper-complete row with no unique physical-owner match
is a mechanically valid scientific `unmatched` outcome. It counts as safety
cost and does not satisfy the source-specific target-B endpoint. Malformed rows,
duplicates, covered-owner repeats, premature STOP, generic continuation, and
over-continuation are likewise explicit outcomes, not instrumentation failures
when receipts pass.

For a 2×2 with mechanically valid cells, report component-wise matched owner
`G/K/L/net`, unmatched count, duplicate count, STOP/admission, and invalid mass.
If any primary cell lacks a qualified source-specific endpoint, set
`source_specific_crossover_status=unqualified`. A
`descriptive_matched_net_tau` may still be emitted from the frozen matched-owner
net arithmetic, but it must be labeled descriptive, kept beside unmatched and
STOP contrasts, and never summarized as a qualified hidden-state interaction
or strict zero. Beside it publish the predeclared charged utility
`net_charged = |G| - |L| - unmatched_rows` and its tau. Never collapse the two,
and never report a zero interaction from the matched-neutral utility alone.
Machine and narrative dispositions must agree.
