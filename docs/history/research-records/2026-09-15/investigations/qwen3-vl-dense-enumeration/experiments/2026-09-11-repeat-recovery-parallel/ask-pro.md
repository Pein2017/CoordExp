# 可选咨询：从重复行惩罚到正确分叉学习

以下内容可直接复制给 GPT-pro。咨询不阻塞已经授权的两条小规模取证；
本地路径不是必要阅读材料，目前没有新训练或电路干预结果。

---

我们在研究自回归视觉检测：输入图片，输出若干完整 object rows，最后 EOS。
每行是 description + 四个离散坐标 token + 统一结构标记。任务本质是无放回
枚举可见实例，而不是重复列出同一区域。GT 不完整，描述和实例粒度也有噪声，
所以不能把 unmatched prediction 当 hallucination，也不能把所有 FN 直接当新对象。

## 已有证据

1. 使用同一2B VLM、固定 Stable50 adapter、greedy/RP1。从8个刻意选出的案例
   做固定前缀续写：7个重复案例加1个正常对照，不代表总体发生率。
   某些小框有真实物体支持，某些不确定。重复常先于无效几何出现。
2. 保留输出历史、换成另一张同尺寸图片：bottle 早期前缀后识别飞机并结束，
   较晚前缀后却继续51行 bottle（33行几何无效）；knife 类似，较晚前缀后继续
   56行 knife（45行无效）。均达到512新 token上限。早晚前缀同时改变长度、
   内容和末行，不构成纯重复剂量实验；换图也不是删除所有视觉信息。
3. 只平移最后一行坐标，保留其余历史和原图，有时能转向其他真实甜甜圈或蛋糕；
   有时仍重复，有时回到相同无效边界。在正常案例上，换图+平移还可以诱发重复。
   所以这些操作不是可靠修复，也不自动提供训练标签。
4. 先前32步 dedup训练从当前学生rollout中找所有后出现的有效框：与任意更早
   有效框 class-blind IoU>0.95即判重复。损失只作用于该行的四个采样坐标：
   q=exp(mean(log p_i)); L=-log(1-q)，按全部有效行数归一化，另有保护KL。
   全384图的严格有效重复582→487，但几何无效行788→888，TP50减少3，
   原先4个达到长度上限的案例都未解决。因此不能把减少有效重复当作成功。
5. Stable50本身并非纯干净GT SFT：主要是局部入口token CE加固定模型轨迹KL。
   原Source就有同4个长度上限案例，严格重复579，对比Stable50的582。
   我们尚未定位训练来源、复制电路、视觉约束减弱的具体机制或小物体特异性。

## 正在准备，但尚无结果的取证

主线：在4个固定失败案例的真实原图/原生重复前前缀 h 上，把此前其他条件下
观察到、经人工确认的不同实例完整行 c 放进去，再自由生成后缀。仅改变下一行，
不带入平移后的旧历史，不拼接旧后缀，不把强制的 c 算自主恢复。每例最多2候选，
保留无效框、旧对象与提前结束的代价。目的是确认可用于学习的正分叉是否存在。

独立机制线：固定图像、唯一实例行集合、历史token数和最后一行，重分配更早
区块中A/B实例的出现次数，并用小规模对称顺序对照。读固定行A/B的分数和自由
续写；不把某个精确行的概率等同于整个IoU邻域概率，不预设已识别纯计数效应。

## 希望你解决的核心问题

假设主线确实找到了可信的 h→c→有用后缀，而原生 h→b′→重复链。
我们拟比较“仅坏行负学习”与“同样负学习+正确完整下一行正学习”，用相同保护
条件，并最终从原图、无强制前缀自然生成来判输赢。

**怎样定义最小而语义正确的学习目标，使它真正改变实例重选/状态推进，而不是
把概率搬到坐标抖动、无效框、错误类别或提前EOS？**

请重点回答：

- 把完整行当负动作到底解决了什么、没有解决什么？同类实例共享description和
  wrappers；逐token惩罚可能伤害正常枚举。精确行偏好也不等于对重复实例集合
  概率的惩罚。有没有无需遍历所有bbox邻域的可行估计或更合适信用分配？
- h来自旧策略、模型更新后不一定再到达h：如何区分固定条件能力提升与自然
  策略的正确递归组合？给出最小的前缀刷新/学习安排，不要默认要完整RL系统。
- 我们的主张可能被什么具体反例推翻？若只允许一个短预算对照，你会保留上述
  对照、改变它，还是认为缺少哪一条必要证据？请给可检查的式子/伪代码或反例。

约束：8卡、2B模型、短预算、现有语言DoRA可训练；当前不加KV/ledger架构、
不建万能matcher，不把未标注物体当负例，不以单独KL或重复指标作为对象保留
证明。完整行正样本可少量人工核验，但没有完整物理owner真值。最终应联合看
自然重复/无效行/长度上限和对象保留，不能靠一律早停过关。

请独立挑战这个 framing。我们希望得到一个有区分力的选择，而不是泛泛的
exposure bias、CE/RL综述或无限扩展的机制实验列表。
