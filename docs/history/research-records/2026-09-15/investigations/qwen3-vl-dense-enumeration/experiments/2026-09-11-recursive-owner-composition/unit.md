# Recursive owner composition: bounded next-experiment admission

## Current contract

From the accepted `positive7-support50-81` (Stable50) composition, do two
ordered, complete, annotation-backed row insertions at actual causal prefixes
produce an all-annotated-owner continuation without losing old owners or
increasing annotation-relative FP, strict repeats, invalid rows or parser
drops, and with native EOS?

This first stage measures conditional witness supply, **not learning or
autonomous completeness**. It supplies a concrete decision about the proposed
next comparison: joint full-witness supervision versus recursive removal of
assistance. No new tokens, KV edits, ledger architecture, GT changes, default
checkpoint promotion or confirmation512 access is authorized by this record.

The user requested independent next-experiment work with eight GPUs and a

## Intervention and evidence

1. Reproduce each selected image's cold, unforced Stable50 continuation.
2. Order the two missing GT rows by the configured `geo_sorted_xy` rule
   (x1 then y1, with deterministic full-box/owner tie breakers). Insert the
   complete first row before the first natural row at/after its x1/y1 location,
   or before EOS if no such row exists. Generate the remaining suffix freely.
3. If the first correction preserves the old owners and burden, and the
   second owner is still missing, insert the second complete row at the first
   eligible boundary in that **actual resulting suffix**, strictly after the
   first inserted row. Generate freely again. Do not splice an old suffix or
   pass off teacher-forced prefix tokens as newly autonomous output.
4. Report the full denominator: baseline failures, one-correction closure,
   first-correction failures, second-correction failures and two-correction
   closure. Report forced row/token counts, replayed prefix tokens, free
   tokens, exact prefix hashes, remaining action budget, IoU50/60/80 owner
   sets, FP, strict repeats, invalids, drops and EOS/caps.

The native global category-aware assignment owns owner metrics. Strict repeat
means a later geometry-valid prediction has IoU **strictly greater than0.95**
against any earlier geometry-valid prediction, regardless of class or GT;
each later row counts once. This phase measures that predicate without changing
the model. Its eventual negative-learning term must use actual student
rollouts, not assume the fixed clean witness contains the failure.

## Decision after this stage

- If complete two-correction witnesses exist, select at most8 in the frozen
  order after target visual review; freeze the learning contrast and dose in
  a follow-on section before training. A joint full-path baseline must be
  present; recursive ordering is a hypothesis, not a theorem.
- If only one-correction closure occurs, report it as such rather than claiming
  recursive composition evidence. If the fixed pool supplies none, close that
  admission result and recommend the cheapest changed contrast explicitly.
- The strongest alternative is that full-path supervision already suffices;
  conditional oracle completion by itself does not support a new architecture
  or predict a learned native improvement.
