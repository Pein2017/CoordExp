# Architecture History

This directory preserves superseded architecture reviews and proposal-era
workflow artifacts for explicit historical reconstruction only. It does not
define current behavior, implementation authorization, or stable contracts.

Use current authority first:

1. `docs/PROJECT_CONTEXT.md`
2. `docs/COORDEXP_SWIFT.md`
3. `docs/SYSTEM_OVERVIEW.md`
4. `docs/IMPLEMENTATION_MAP.md`
5. the relevant stable contract under `openspec/specs/`

The archived `BLUEPRINT.md`, `DECISIONS.md`, lifecycle registry, approval-card
process, and super-power references must not be imported into a new change as
requirements. Revalidate any useful idea against current code and contracts.
