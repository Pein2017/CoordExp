# Public literature for trustworthy natural set completion

This is a maintained reading map for external evidence and reusable methods. It complements [our research frontier](../index.md); [CONVENTIONS.md](../CONVENTIONS.md) owns placement and maintenance. Question pages own the combined interpretation of public papers and our results. A paper's age or completed reading does not make it archival.

## Use from a local research question

Start from the local result and its strongest counterexample, select the matching question route below, then read the relevant paper note and original sections. Ask what the outside evidence actually changes: a competing explanation, an intervention/control, an evaluation boundary, or a decision about the next experiment. Reuse checked evidence; expand to other public literature only for a decision-bearing gap. This collection is a starting set, not an exhaustive prior-art search or a launch queue.

**Reading scope:** `Selected sections` links a substantive note with its exact version and scope; it does not mean full-paper review or local replication. `Abstract only` supports abstract-level identity/claims, not method validation. `Intake only` retains the user's recommendation; bibliographic identity and substantive claims still need primary-source checking before use. Topic placement for intake-only entries is provisional. The table's numbers preserve the original source numbering, not priority.

## Interpretation boundaries worth retrieving

- For a localized-readout explanation, compare [Foveated's synthetic and natural-image gap](papers/2608.00726-foveated-probes.md) with the local [capacity/readout question](../questions/capacity-and-readout.md).
- For an instance-selection explanation, keep [externally steered gaze](papers/2606.14703-gaze-heads.md), [category-level verbalization](papers/2609.18823-ocr-heads.md) and [single-instance localization](papers/2605.19792-object-localization.md) distinct from autonomous next-instance selection.
- For history takeover, inspect the [PCD null counterexample](papers/2609.02000-temporal-causal-drive.md) before treating temporal growth as causal evidence.
- For a learning proposal, distinguish [prompt-off preservation](papers/2609.11310-soft-prompting.md) from retention while adaptation is active, and [annotation-defined set verification](papers/2608.25299-pointrl.md) from exhaustive physical truth.

These are retrieval cues. Cross-paper conclusions, local acceptance and any proposed follow-up remain with the linked question and experiment owners. Add a paper note only when there is substantive evidence or a method to retain; unread entries need no empty files.
