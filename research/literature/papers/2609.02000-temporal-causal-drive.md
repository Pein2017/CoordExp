# Temporal Causal Drive

## Source and reading scope

**Who Drives the Probability Game of VLMs? A Temporal Causal Drive Evaluation Framework**, [arXiv:2609.02000v1](https://arxiv.org/html/2609.02000v1), 2026-09-02. Checked 2026-09-17: selected definitions, temporal results, randomized-intervention description and supplementary derivation (§§3–5, 8). No local model replication or implementation audit.

## Tested conditions and observations

The paper scores fixed generated sequences under image, question and prefix source interventions. It reports temporal PCD/QCD/VCD patterns on VQA/video tasks and validates some estimates against held-out randomized contexts. Its visual drive is defined with a null question; it is not automatically the effect of removing vision while retaining the actual task question.

## Authors' interpretation and our assessment

The authors interpret rising prefix drive as increasing reliance on generation history. Source-separated, time-indexed diagnostics are useful, but their normalization must pass a null example before we interpret a slope mechanistically.

## Limits and a local mathematical counterexample

Equation 5 defines

\[
\mathrm{PCD}_t = \log_2\frac{P(A_t=a_t\mid do(A_{<t}=a_{<t}))}{P_0(A_{\le t}=a_{\le t})}.
\]

**Our derivation:** let every output token be an independent fair binary variable under every source condition. Fixing history has no effect on the next token. The numerator is nevertheless \(1/2\), the denominator is \(2^{-t}\), and PCD equals \(t-1\). Thus an increasing PCD alone cannot identify increasing prefix-to-next-token influence; fixing an increasingly unlikely prefix contributes to the score.

The following reproduces the counterexample without model calls:

```python
from math import log2

for t in (1, 2, 4, 8):
    pcd = log2(0.5 / (0.5 ** t))
    next_token_effect = log2(0.5 / 0.5)
    assert pcd == t - 1 and next_token_effect == 0
```

This limits the slope interpretation; it does not reanalyze or invalidate every empirical result in the paper.
