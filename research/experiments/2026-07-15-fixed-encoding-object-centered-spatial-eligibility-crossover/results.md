# Fixed-Encoding Object-Centered Spatial-Eligibility Crossover Results

## Verdict

Accept the executed artifact and stop this unit as **inconclusive**. Hard
post-vision language-decoder image-token key eligibility is causally potent
and spatially selective, but this panel does not establish recurrent complete-
row owner switching or sufficiently general release from unrestricted visual
competition.

Only image `139` satisfies the complete preregistered case rule. Image `12120`
switches geometry and the complete row but not description ownership. Images
`632`, `2299`, and `12639` show one-sided spatial redistribution without a
complete target-versus-competitor reversal. Image `9400` is excluded because
its all-image-allowed four-dimensional-mask no-op drift exceeds the frozen
threshold.

The panel therefore does not authorize a free-row replay, phase-specific unit,
training screen, layer sweep, or architecture promotion.

## Executed Contract and Trust Gates

- Model: Qwen3 Vision-Language (`Qwen3-VL`) 2B with the geometry-sorted
  step-4887 Weight-Decomposed Low-Rank Adaptation (`DoRA`) adapter.
- Model execution: full Institute of Electrical and Electronics Engineers 754
  32-bit floating point (`float32`), physical batch size one, Scaled Dot
  Product Attention (`SDPA`).
- Prefix: one fixed reset/base detection prompt per image.
- Scoring: teacher-forced, no cache, with no repetition penalty.
- Visual execution: the original image was encoded once; the primary and all
  DeepStack features were captured, hashed, and replayed exactly for candidate
  selection and every arm.
- Position execution: explicit Multimodal Rotary Position Embedding
  (`M-RoPE`) identifiers came from the ordinary two-dimensional mask and were

## Phase Interpretation

### Image 139: complete regional switch, weak competition release

The target vase and competitor clock switch semantic ownership strongly:

```text
first differing description gamma: +5.986 under target, -8.864 under competitor
complete description gamma:         +8.226 under target, -4.429 under competitor
geometry gamma:                     +0.181 under target, -1.780 under competitor
```

This is not a generic row-entry pulse: row-entry crossover is zero and the
target-window change in row-entry-versus-terminal log odds is only `+0.032`.
However, unrestricted-competition release is weak. The target row improves by
only `+0.057` natural-log units per token, barely above the preregistered
threshold, while the competitor row becomes `-1.049` worse under its own hard
window. Much of the large crossover therefore comes from non-owner
suppression, not robust two-sided owner release.

### Image 12120: geometry routes, description does not

The person and tennis-racket rows reverse under the geometry and full-row
scores, but both windows still favor the person description:

```text
description gamma target:     +2.382
description gamma competitor: +2.321
geometry gamma target:        +1.854
geometry gamma competitor:    -0.947
```

This is a clean phase-separation anchor: spatial key eligibility can redirect
the coordinate path without overcoming the language-side description prior.
It occurs once, so the preregistered recurrence gate for a new phase-specific
unit is not met.

### Same-category cases: spatial selectivity without stable instance choice

The book and person pairs have no lexical identity contrast. Their target
windows improve the target-versus-competitor margin relative to competitor
windows, but images `632` and `2299` degrade both owner rows relative to full
eligibility. Image `12639` is the strongest one-sided rescue: target full-row
release is `+0.532`, but the target-window margin remains `-0.011`, just short
of an ownership reversal.

These cases show that fixed visual features expose geometry-sensitive spatial
information to the decoder. They do not establish an instance lock, commit,
or reliable choose-one-object operation.

The windows are object-centered but not object-pure. For example, image
`139`'s target window contains the centers of two official vases and one
person; image `12120`'s target window contains four official people. The dense
same-category windows similarly cover several people or books.

The supported claim is therefore **region-conditioned owner-row routing**, not
a pure visual instance pointer. The source visual features are also already
globally contextualized before this intervention.

## Supported

1. A post-vision language-decoder image-token key-eligibility seam exists and
   can causally move description and coordinate likelihoods while visual
   features, prefix, positions, and model weights remain fixed.
2. Fixed full-image visual features retain spatially usable information after
   the vision tower; input-level pixel masking is not the only way to expose a
   missed region.
3. Hard restriction sometimes produces a true regional semantic-plus-geometry
   owner switch, and sometimes only phase-specific or one-sided routing.
4. Generic continuation changes do not explain the owner interactions: the
   candidate rows share the same row-entry token, while their later semantic
   and coordinate likelihoods diverge by region.
5. Global context is useful for many rows. A hard local window frequently
   degrades both candidates even when their relative margin changes.

## Not Supported

- Unrestricted visual competition is not established as the dominant cause of
  low recall.
- Hard spatial eligibility is not a reliable general detector intervention.
- A stable instance pointer, row lock, commit, coverage ledger, or autonomous
  traversal state is not demonstrated.
- The result does not establish free-row switching, recall or Average
  Precision improvement, population prevalence, or causal necessity of the
  native unrestricted route.
- No 256-image training screen or final architecture is authorized.

## Route Decision

Stop the frozen unit. Do not promote image `139` alone, do not relax the image-
`9400` no-op threshold, and do not launch a phase-specific unit solely from
image `12120`.

The most useful retained anchors are:

- image `139` for complete regional semantic-plus-geometry switching;
- image `12120` for geometry routing without description ownership; and
- image `12639` for strong one-sided same-category rescue.

A future independently specified unit may use those anchors to ask whether a
soft, context-preserving spatial bias has an interior operating point between
full eligibility and destructive hard restriction. That is a new hypothesis,
not an extension or positive conclusion of this unit.
