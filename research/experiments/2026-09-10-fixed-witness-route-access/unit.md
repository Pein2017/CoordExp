log-probabilities, target-vs-best-other full-vocabulary margins, target/top1
IDs, exact first-fork position, and first non-argmax point along the candidate.
Keep common-prefix, gained-target-row, other-row and wrapper/EOS summaries.

Use the existing greedy trajectories on the same32 images for baseline parity
and semantic reconciliation. An early equivalent coordinate fork is not
automatically an owner-access bottleneck. Report all gained/lost owner IDs from
the accepted reduction without treating exact candidate reproduction as the
owner outcome. Sum-logprob changes compare the same sequence across models;
also report lengths/per-token rates instead of ranking unequal sequences by
raw totals. Aggregate by image as well as sample, not independent-owner trials.

CPU read: inspect advantage-weighted sibling branch support at identical
prefixes; shared-prefix cancellation is a direct objective property, not a
promise that shared parameter updates leave those logits unchanged.

No backward/gradient-inner-product pass by default. No estimate of the new
policy's sampled expected reward from these selected fixed sequences. The
parallel row probe is not gated on this diagnostic's result.
