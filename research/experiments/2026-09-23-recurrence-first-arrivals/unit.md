## Predecessor, incremental question and claim boundary

[Native row choice](../2026-09-21-native-row-choice/lead-results.md) found no
unvisited candidate beating the actual repeated complete row in its three
admitted states (two images; other states HOLD). This is a finite negative,
not a proof that the global best row repeats. [Visual instance binding](../2026-09-21-visual-instance-binding/lead-results.md)
found differentiated regional support for supplied candidates, which does not
prove autonomous owner selection. [Spatial progress recovery](../2026-09-21-spatial-progress-recovery/lead-results.md)
was not selective against its strongest noncrossed and normal controls.
[Phase/role intervention](../2026-09-19-recurrence-phase-decision/lead-results.md)
did not establish a general first-ever-onset signature. The latest
[prefix-content transfer](../2026-09-23-recurrence-local-prefix-content-transfer/results.md)
restored the repeated coordinate in only one of three selected transitions.

This package is a **chronological extension plus a minimal branch-release test**,
not a new scoring algorithm or a reopening of successful-donor/phase searches.
It newly pairs adjudicated first-valid versus first-invalid proposals, their
first three arrivals, and normal-progress controls. It asks whether a finite
whole-row preference for a correct new owner can coexist with a native greedy
return, and whether one changed coordinate lets the remaining row realize that
new owner freely. Neither temporal relocation alone nor conditional grounding
is a new mechanism finding.

Active question: **From the native first-three-arrival states, does replacing
only the first differing coordinate with a fixed new-owner candidate's token
redirect the freely generated remainder to that owner, under native/sham replay
and finite whole-row preference checks?**

Working explanation: locally greedy coordinate choices can realize the old
proposal despite a better supported complete new-owner row in the tested set.
Strongest alternative: the observed state already assigns the old complete row
more probability than every tested new row; a supplied coordinate may enable
grounding without explaining the native choice. The alternative is a finite
preference statement, not proof of a preselected internal object.

## Finite candidates and native decision evidence

For each family freeze at most two distinct, physically supported, same-class
new-owner candidates before scoring. Prefer owners remaining unvisited through
the family's analyzed window; choose nearest annotated/accepted box centers to
the first proposal, with stable owner ID as tie-breaker. This is an oracle-assisted
selection rule, not a claim of model discovery. Freeze one canonical quantized
row per owner using the maintained data/coordinate serializer. Do not search
alternate boxes, descriptions or tokenizations for a favorable score.

At each native arrival boundary let A be the actual emitted complete row and N
one fixed new-owner row. Both include all grammar tokens, description, all four
coordinates and the row terminator. Use full-vocabulary log probabilities under
the **same native history**. Record `D = log P(N | H) - log P(A | H)` per candidate;
never interpret a maximum or sum over this set as total owner probability or
global row MAP. Candidates already visited at a landmark are no longer eligible
as new; report that fact rather than changing their identity silently.

Along native emissions retain raw token IDs, role boundaries, global winner/
runner-up, selected alternative-coordinate logits and normalization terms.
Track alternatives only where their literal prefix remains compatible. Once a
native coordinate contradicts N, label N prefix-incompatible. **The resulting
lexical exclusion or zero completion probability is not evidence of a latent
attractor or a loss of visual information.** Counterfactual suffix scores under
a hybrid prefix describe that hybrid, not the original N row.

Do not use decoded hidden-state owner probes as decisive evidence without a
separately authorized and qualified causal-use test. Full hidden-layer/KV scans
are not necessary for this first decision and are outside the package.

## Smallest coordinate branch and outcomes

For each frozen A/N pair identify the FIRST differing coordinate token j. The
row opener, description and preceding coordinates must be literally shared.
At that exact native decision supply only N's token at j, then decode the rest
with the original greedy policy. If a noncoordinate differs first, or no
coordinate remains to be freely generated (j is y2), the pair is branch-HOLD;
its finite row score remains valid evidence. Never force an entire new box.

Run a native replay/free continuation, an A-token supplied sham through the
same branch consumer, and the N-token branch. Reuse an identical native/sham
only through an explicit shared manifest; do not rerun it per candidate. Each
branch stops at EOS, after the current row plus two further complete rows, or
256 freely generated tokens, whichever comes first. An incomplete or malformed
row, cap and EOS are outcomes, not technical failures. Report supplied, shared
native and freely generated coordinate counts separately by slot.

Primary release outcome is whether the first completed branch row corresponds
to N, A, another accepted owner, a confirmed false proposal, UNKNOWN, or no
complete row. Annotation-backed class/IoU50 matching is a proxy; retain IoU80,
actual geometry and overlay review, and do not force ambiguous overlaps into
one physical owner. Credit conditional N realization only after coherent
geometry and unique owner attribution; supplied coordinates receive no native
prediction credit. The extra two rows describe immediate continuation only.

Apply the same candidate/branch rules to normal controls and first arrivals.
A generic ability to follow a supplied coordinate is not recurrence-specific.

## Decision rules

Report three separate results per arrival: finite row ranking, native first
coordinate divergence, and conditional free-remainder realization. A strict
finite/local-decoding witness requires N to outrank A at the row boundary while
native greedy emits A. A successful N branch adds conditional realization
evidence. Their conjunction supports a local mismatch between complete-row
preference and greedy realization in this candidate set; it does not establish
that the native model had selected N internally.

If A beats all tested N rows, report consistency with an old-row preference,
not proof of a pre-row owner commitment. If N branches work but no finite witness
exists, conclude only conditional grounding/realization. If normal controls
show the same effect, do not label it specific to recurrence. A negative finite
search cannot exclude other boxes/owners or a different row-level explanation.

Compare first-to-second and second-to-third within family; do not count three
arrivals as three independent images. Keep first-valid/invalid, invalid reason,
source population and adjacent/nonadjacent strata separate. Missing later
arrivals after EOS are observed nonreturn; cap is right-censoring. Small counts
own descriptive case verdicts, not a population rate or a universal recursion.
Mixed results may remain unidentified. No majority threshold is invented after
seeing them.

Positive finite witnesses prioritize a later study of coordinate realization;
conditional-only success prioritizes distinguishing native selection from
available grounding; absent support ends this diagnostic as inconclusive. None
automatically releases another experiment, decoding policy or training change.
