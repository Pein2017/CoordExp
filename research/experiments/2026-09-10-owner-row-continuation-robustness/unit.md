# Frozen branches and semantic accounting

For each admitted case at the same P, run four Source branches:
1. exact original B row, released after the native completed-row boundary;
2. A forced only through its first differing coordinate token relative to B,
   then release the remainder of that row and suffix;
3. complete verified sampled A row, released at the same completed-row boundary;
4. complete A' variant, released at that same boundary.

Fifth descriptive control: the same complete A row after its original sampled
history, then greedy release. Record covered sets and remaining obligations at
both release points. Only compare common not-yet-covered obligations where
meaningful; an empty common remainder or incompatible workload is explicitly
non-discriminating, not evidence of a successor defect.

The forced full A is not autonomous discovery. Partial-A completion is only
conditional realization. Check whether displaced B reappears freely in the
suffix; do not count forced B as preserved. Report other Source suffix-owner
gains/losses separately and retain global category-consistent IoU50/60/80
matching, fixed-GT identity witnesses and direct-action incidence information.
Flag assignment redistribution/category correction/IoU threshold effects;
do not call every count change a new physical discovery.

All comparisons retain complete outputs, malformed rows and caps. Report
TP/FP/FN/F1, valid predictions, strict later pixel-IoU>.95 repeats, parser
drops, EOS, complete action length and common free-row-horizon progress.
More correct rows/length alone is not failure; extra repetitions and budget
exhaustion remain visible. Unknown unmatched predictions remain unknown.
