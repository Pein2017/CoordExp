# Fixed-Encoding Conditional Downstream Layer-Output Residual-State Portability Gate

## Question

Does an eligible hard regional donor compile a conditionally portable
downstream language-decoder layer-output state after the routing intervention
is removed, or does its realized phrase or geometry path require persistent or
distributed hard exclusion?

This is the only question in this unit. It does not ask which architecture
should implement object selection, commit, coverage, or stopping.

## Why This Is the Next Discriminator

The completed fixed-encoding series establishes three facts within its bounded
teacher-forced panels:

1. hard post-vision image-key eligibility can causally switch semantic or
   geometry ownership while visual features, tokens, positions, and model
   weights remain fixed;
2. direct row-scoring queries are a strong geometry-routing seam, but image
   `139` also requires earlier-query computation for its cross-category
   semantic phenotype; and
3. uniform finite positive bias and the count-balanced phase-restricted soft
   operator do not provide reliable matched owner control. The latest soft
   operator failed both matched controls, so its crossed arms are not
   interpretable.

The remaining uncertainty is downstream of attention magnitude. Hard routing
may either compile a reusable conditional downstream state, or work only while broad
non-owner evidence remains excluded. A one-time residual-state transplant
separates these explanations without another dose sweep or a proposed final
architecture.

Historical painted-image probes provide the prespecified observation seams:
first-description-token control becomes strongly causally readable around
language-decoder layers `20` through `23`, while layer `13` is an established
early negative control. Those historical results motivate the selected layers;
they do not supply evidence for the present hard-routing hypothesis.

## Terminology

- **Hard Regional Donor**: a run using the already verified hard regional
  image-key eligibility operator. Its returned layer-output state is captured
  at one declared decoder boundary.
- **Eligible Donor**: a hard regional donor whose persistent hard endpoint
  realizes a valid donor-owned phrase or coordinate path and whose exact
  realized path has non-destructive absolute release relative to unrestricted
  execution. An ineligible donor remains a negative or mechanics control and
  cannot support a portability claim.
- **Unrestricted Recipient**: the same image, prefix tokens, position
  identifiers, visual features, model, and row boundary evaluated with normal
  full image-key access.
- **Conditional Downstream Layer-Output Portability**: causal transfer of an
  eligible donor's realized phrase or coordinate path after replacing one
  unrestricted recipient layer-output state at the identical boundary. The
  claim is conditional on the frozen donor, recipient, boundary, and later
  decoder computation; it is not a claim that the state is an autonomous or
  universal object representation.
- **One-Time Residual-State Replacement**: replacement of the unrestricted
  recipient's returned boundary-token layer output with the detached donor
  layer output at one declared zero-based language-decoder block during
  prefill. The hard routing mask is not used for recipient prefill or later
  token calls, and the state is not re-injected at later token positions.
- **Realized-path release**: change in the exact phrase or four-coordinate
  sequence realized by the persistent hard donor, scored under replacement
  versus the unrestricted recipient.
- **Donor-swap directionality**: change in target-minus-competitor owner margin
  when the donor is changed from the target-region hard run to the competitor-
  region hard run.
- **Phrase-geometry consistency**: the generated description and generated
  four-coordinate box are both attributed to the same donor object.
- **No-operation control**: unrestricted residual state replaced by the
  byte-identical unrestricted state from the same layer and boundary.

## Donor-Eligibility Gate

Portability can be interpreted only for an eligible donor. For each candidate
donor, first run the bounded persistent hard endpoint and retain its exact
realized phrase or four-coordinate sequence. Score that exact realized
sequence under:

1. unrestricted execution;
2. the persistent hard donor; and
3. the one-time replacement recipient.

The persistent hard endpoint must close a valid row or valid coordinate suffix,
must realize the donor object's phrase or geometry, and must give that exact
realized path absolute release of at least `-0.05` natural-log units per token
relative to unrestricted execution. Otherwise the donor is ineligible and may
serve only as a negative/control. Canonical Common Objects in Context (`COCO`)
rows and pairwise canonical margins remain diagnostics; they cannot establish
donor eligibility or portability.

Image `139` is already adjudicated. Under the target-vase hard endpoint, the
actual first token is identifier `79`, decoded as `p`; the canonical vase token
has rank `3`, and its absolute release is `-0.6807279587`. The vase donor is
therefore ineligible and remains only a negative/control. The competitor-clock
hard endpoint realizes the clock phrase with non-destructive release and is
the only eligible image-`139` semantic donor. Do not search for a replacement
case or reinterpret the vase canonical row as a positive donor.

### Image-632 Geometry Ownership and Eligibility Contract

Image `632` uses a different, geometry-specific contract. Both frozen rows
share the exact prefix

```text
<|object_ref_start|>book<|object_ref_end|><|box_start|>
```

and differ only in their four coordinate identifiers. Phrase equality can
therefore never establish instance ownership.

The target and competitor donors must use the exact row-scoring-query-only
hard operator from the parent receipt. Two query ranges must be distinguished:

- for teacher-forced scoring of a complete row containing `R` target tokens,
  the target-token scoring queries are `P-1` through `P+R-2`; and
- during generation from an already materialized partial row containing `K`
  tokens, the active next-token queries are `P-1` through `P+K-1`, including
  the final current token whose state predicts the next token.

Therefore the initial partial row ending in `BOX_START` must restrict the
`BOX_START` query that predicts `x1`. After each generated coordinate,
persistent generation rebuilds the query-scoped mask through the new final
query. Equivalently, it uses the leading square slice of the complete parent
row-query mask while retaining the final available query. All pre-row and
non-row queries retain ordinary causal access. An all-query regional mask is a
different intervention and invalidates the run.

Generation begins after the existing `BOX_START` token. The only valid suffix
is exactly:

```text
x1 y1 x2 y2 <|box_end|>
```

All four coordinates must be coordinate tokens, `BOX_END` must be final, and
End-of-Sequence, truncation, an extra coordinate, or any trailing token is an
invalid path. The complete row may be reconstructed only for shared scoring
utilities.

Decode the four coordinate bins into normalized `xyxy` coordinates. For a
generated box `b`, designated donor box `b_d`, and paired book box `b_p`,
define:

\[
D_d=\lVert b-b_d\rVert_1,
\qquad
D_p=\lVert b-b_p\rVert_1.
\]

Geometry ownership passes only when all of the following hold:

1. the suffix is valid and naturally closes;
2. `D_d < D_p`, with ties failing; and
3. Intersection over Union with `b_d` is at least `0.30`.

Report both normalized distances and Intersection over Union to both books.
Neither phrase equality nor relative distance without the absolute
Intersection-over-Union floor establishes ownership.

For each donor, retain its actually generated four-coordinate path. Score
those exact four coordinates under unrestricted execution, persistent hard
routing, and one-time replacement. Donor eligibility uses the mean release
over the four coordinates only and requires release at least `-0.05` natural-
log units per coordinate plus geometry ownership. `BOX_END` release is
reported separately and cannot contribute to eligibility or promotion.

## Fixed Execution Invariants

- Model: Qwen3 Vision-Language (`Qwen3-VL`) 2B with the geometry-sorted
  step-4887 Weight-Decomposed Low-Rank Adaptation (`DoRA`) adapter.
- Numerical execution: full Institute of Electrical and Electronics Engineers
  754 32-bit floating point (`float32`).
- Attention implementation: Scaled Dot Product Attention (`SDPA`).
- The source image is encoded exactly once per anchor. Primary and all
  DeepStack visual features are replayed identically across donor, recipient,
  and control arms.
- Prefix tokens, canonical rows, boundary token, image-token indices,
  Multimodal Rotary Position Embedding (`M-RoPE`) position identifiers, and
  regional supports are inherited exactly from the conclusion-owning parent
  receipts.
- Donor and recipient token histories must be identical through the patched
  boundary. A state from a different token history is ineligible.
- No repetition penalty, logits processor, crop, resize, pixel edit, image
  re-encoding, candidate change, support change, or End-of-Sequence
  suppression is allowed.
- The patch seam at zero-based decoder block `L` is the returned layer-output
  tensor after that entire block. Replace only batch index `0` at the exact
  absolute boundary-token position; preserve every other batch and sequence
  position byte-identically. Donor capture and recipient replacement are
  separate forwards.
- Capture the hard donor state and discard its cache. Start a fresh, fully
  unrestricted recipient prefill; replace exactly one returned block-`L`
  boundary state; then remove both donor-capture and recipient-replacement
  hooks before every later token call. Continue only from the patched
  recipient's cache.
- Because replacement occurs after block `L` returns, block `L`'s own cached
  keys and values remain unrestricted. Only blocks `L+1` through the final
  block can cache and carry consequences of the replaced state. The receipt
  must attest this exact causal boundary; the claim is conditional downstream
  layer-output portability, not whole-model state replacement.
- The teacher-forced score path uses raw model logits, no cache, scores each
  exact realized donor phrase/path, and reports all four coordinate slots
  separately. The bounded free continuation uses the patched recipient cache
  and stops at the first complete row boundary or a fixed safety cap. Malformed
  rows are retained as invalid and are never repaired silently.

Before residual results are interpreted, the run must reproduce only the exact
mapped parent arms at the selected boundary and decision phases. Require the
same actual top token identifiers, the same ranks for the donor-realized and
canonical diagnostic tokens, and maximum absolute drift at or below `1e-4`
for the relevant first-description, realized-phrase, and coordinate-path log
probabilities. Unrelated row tokens are outside this reproduction gate.
Failure is an invalid execution, not negative mechanism evidence.

## Required Arms

Every primary anchor runs the following conditions from the identical
unrestricted recipient prefix:

1. **Unrestricted Baseline**: ordinary full image-key access with no state
   replacement.
2. **Unrestricted Self-State No-Operation Control**: capture the unrestricted
   state in one forward, detach it, then replay it into a separate fresh
   unrestricted recipient forward at the identical seam.
3. **Target Hard-Donor Replacement**: replace the unrestricted boundary state
   once with the state captured under target-region hard routing.
4. **Competitor Hard-Donor Replacement**: replace the unrestricted boundary
   state once with the state captured under competitor-region hard routing.
5. **Layer-13 Hard-Donor Negative Control**: repeat the target and competitor
   replacements only at prespecified early language-decoder layer `13`.

The layer-`13` pair is one negative-control family. It tests whether any hard-
routing state or state replacement generically perturbs the output. It is not
an exploratory layer search.

For image `632`, the only permitted hard donor arms are
`target_row_query_only_hard` and `competitor_row_query_only_hard` from the
frozen row-scoring-query-only parent receipt. Its embedded
`parent_hard_endpoint` is not a donor arm. The receipt must structurally attest
that only the declared row-query range changed and that every other query and
non-image key remained equal to the ordinary causal mask.

For each hard donor, retain the corresponding persistent hard-routing endpoint
as the parent reference and eligibility gate. The reference is not a residual-
replacement arm and must not be pooled with the unrestricted recipient.

## Measurements

For phase `p`, donor `d`, and exact realized donor sequence `y_d`, define
realized-path release:

\[
R_{p}(y_d,d)
=
S_{p}(y_d\mid\operatorname{replace}(d))
-
S_{p}(y_d\mid\operatorname{unrestricted}),
\]

where `S_p` is mean raw selected-token log probability. Canonical target-minus-
competitor margin under donor `d` remains a diagnostic:

\[
\Gamma_p(d)=S_p(\mathrm{target}\mid d)-S_p(\mathrm{competitor}\mid d),
\]

and donor-swap directionality as:

\[
D_p=\Gamma_p(\mathrm{target\ donor})-
\Gamma_p(\mathrm{competitor\ donor}).
\]

Positive `D_p` means the target donor shifts the canonical diagnostic toward
the target relative to the competitor donor. Pairwise margins never substitute
for donor eligibility, realized-path release, or the actual top token.

Record for every eligible arm:

1. actual top first-description token identifier and text, plus the exact
   realized persistent-donor phrase sequence;
2. realized-path release under persistent donor and replacement for the phrase,
   each of `x1`, `y1`, `x2`, and `y2`, complete geometry, row closure, and
   complete row; canonical `COCO` row scores remain separately labeled
   diagnostics;
3. donor-swap directionality for those same phases;
4. generated description, every generated coordinate token, parsed box,
   distance and Intersection over Union (`IoU`) to both owner boxes;
5. phrase-geometry owner consistency;
6. row-close token, natural closure within the cap, parser validity, and any
   malformed or truncated output; and
7. absolute non-owner suppression, so a margin win caused only by destruction
   remains visible.

## Competing Predictions

### Conditional Downstream Layer-Output Portability

- On image `139`, the eligible clock donor makes `clock` the actual top semantic
  token after normal unrestricted decoding resumes and raises the exact
  realized clock phrase path. The ineligible vase donor is not expected or
  required to produce `vase`.
- On image `632`, any eligible one-time pre-`x1` donor replacement moves the
  complete four-coordinate sequence and generated box toward that donor book
  without destroying the realized donor path.
- Layer `13` controls remain close to unrestricted behavior.

### Persistent or Distributed Exclusion

- A late donor replacement may flip the immediate token, but later phrase,
  coordinates, or closure return to the unrestricted basin.
- Image `632` geometry does not follow a one-time donor after hard eligibility
  is removed, although the persistent hard endpoint remains strong.
- No informed one-site replacement reproduces its eligible donor's exact
  realized phrase or geometry path.

### Generic Suppression State

- Donor replacements mainly lower an alternative canonical row rather than
  raise the eligible donor's exact realized phrase or geometry path.
- Pairwise margins move while actual top tokens are unrelated, or layer `13`
  and donor-swap controls produce effects of similar magnitude.
- The ineligible image-`139` vase control or one-sided image-`12639` negative is
  spuriously converted into an apparently symmetric story through non-owner
  collapse.

### Phase-Specific Control State

- The eligible image-`139` clock first-description patch transfers its realized
  semantic path but fails to carry donor-consistent geometry through the row.
- An eligible image-`632` pre-`x1` layer-`23` replacement transfers its realized
  geometry path.
- This pattern supports separately timed semantic and geometry carrier states,
  not one monolithic object cursor.

## Trust and Promotion Gates

Interpretation requires all of the following:

1. the narrow mapped-arm parent reproduction and donor-eligibility gates pass;
2. unrestricted self-state replacement has maximum selected-token drift at or
   below `1e-4`, exact actual top tokens, and exact generated row under a fixed
   deterministic decode, despite capture and replacement occurring in separate
   forwards;
3. captured donor and recipient boundary token histories, feature hashes,
   position identifiers, and layer indices match exactly;
4. every interpreted residual effect is at least ten times the corresponding
   self-state no-operation drift; and
5. the receipt records donor eligibility, mapped parent-arm name, donor and
   recipient request identities, zero-based block index, returned-layer-output
   seam, batch index, absolute boundary position, replacement count, hook
   removal, cache lineage, generated-token count, and proof that no other
   position was replaced.

Promote **bounded one-sided conditional downstream layer-output portability**
for an individual eligible donor only if all of these scientific conditions
pass:

1. the persistent hard endpoint passes donor eligibility, and replacement
   preserves its actual decisive top token or full four-coordinate owner path;
2. replacement realized-path release is at least `+0.10` natural-log units per
   token and recovers at least one half of the positive persistent-hard realized-
   path release, with an effect at least ten times self-state no-operation
   drift;
3. the replacement continuation is valid and naturally closed; for a geometry
   donor, every coordinate token is retained and the generated box is closer
   to that donor object than to the paired object;
4. layer-`13` controls do not satisfy the corresponding semantic or geometry
   realized-path rule; and
5. canonical pairwise movement, ineligible donors, and non-owner suppression
   are not used to complete a portability claim.

For image `632`, `owner_path_match` means the frozen geometry-ownership rule
above, `path_phase` is `coordinates`, and realized-path release is the
coordinate-only mean. A layer-`23` donor passes only if its replacement box is
owned by that donor under the same rule used for persistent-donor eligibility.
If the corresponding layer-`13` donor satisfies the same rule, it vetoes the
layer-`23` claim.

## Stop Rules

- If parent reproduction or self-state no-operation fails, stop as invalid and
  repair only the execution contract. Do not interpret mechanism outcomes.
- If neither layer `20` nor layer `23` transfers the eligible image-`139` clock
  path and no eligible layer-`23` pre-`x1` image-`632` geometry path transfers,
  close one-site conditional downstream layer-output portability at these
  informed seams. Do not answer with another dose sweep, broad layer sweep, or
  attention-head search.
- If donor states move canonical pairwise margins without eligible realized-
  path release, actual donor tokens, or donor-consistent geometry, classify
  generic suppression and close the conditional portability interpretation.
- If only phase-specific portability passes, stop after recording the bounded
  split. Do not add a second residual site inside this unit.
- If a bounded one-sided or phase-specific portability gate passes, the next
  question becomes how clean visual computation synthesizes that conditional
  state. Do not extend this unit
  into training, a renderer, a selector, a ledger, or an architecture.
