# Current-header Q/K/V clamp: CPU feasibility candidate

Status: **candidate route evidence only**. This review made zero model, vision, CUDA, or GPU calls. It does not admit a run or set a scientific threshold. Exact file bindings and the finite cell ledger are in [header-clamp-bindings.json](header-clamp-bindings.json).

## Decision and evidence boundary

The accepted older K/V split has a shared V-primary **NONPASS** and a shared K-comparator **NONPASS**: AF native-to-joint TV is 0.782429, with V-to-joint and K-to-joint ratios 0.144726 and 0.255575; FF native-to-joint TV is 0.530136, with ratios 0.976821 and 0.986966. These are accepted observations, not results of this feasibility work. A later clamp could ask whether this four-corner pattern in **each base** persists when current-header attention read states cannot adapt. Fixed Q/K/V permits the direct older-slot K-by-V interaction in `softmax(QKᵀ+mask)V`; later residual/MLP nonlinearities remain. Retention would show that current-header Q/K/V adaptation is unnecessary for the specified pattern under this intervention; collapse would implicate adaptation under the joint clamp. Neither is a natural mediation fraction or a literal circuit identification.

The source remains refined-03, four requests in the saved order, target index 2 (`coco2017_train_000000351017`), untied checkpoint and original images. AF is native historical `[A,F]`; FF replaces only earlier A geometry with F geometry. The older physical cache span is `[1362,1371)`, latest `[1371,1380)`, and common **replayed**, not freely chosen, person header `[1380,1384)`. Earlier/latest rotary spans are `[387,396)`/`[396,405)` and header `[405,409)`. AF target x1 has the original source trace; FF target x1 is counterfactual and has a saved full-vector reference, while companion source traces remain bound. The latest contextual cache is fixed **within each base**, but AF and FF latest caches differ. All four older corners (native, joint, V-only, K-only) must remain in both bases; cross-base comparison is not a common-Q comparison.

## What exists and what is missing

The accepted attempt saved 14 full-batch vocabulary vectors, input/attention/rotary hashes, historical K/V and their segment hashes, all-layer consumers, and restoration evidence. Its `historical-blocks.pt` has only older/latest target K/V (`28 × 8 × 9 × 128` FP32 per axis/base). The anchor vectors and consumer JSON do **not** contain current-header normalized Q, normalized K, or projected V tensors. The older key cache is post-RoPE and cannot supply native header Q or the missing pre-RoPE tensors. The old six-token clamp reference belongs to a different source/state and cannot be transplanted. A prospective execution therefore needs fresh, separately captured AF and FF native-anchor header tensors before clamped treatment calls.

The installed model config and maintained attention source give, at each of 28 text layers, `q_norm` output `[4,4,16,128]`, `k_norm` output `[4,4,8,128]`, and `v_proj` output `[4,4,1024]`; only batch row 2 is captured/replaced across **all four positions**. Captures per base/layer are Q `[4,16,128]`, K `[4,8,128]`, V `[4,1024]`, FP32. The two-base target-only tensor payload is 3,670,016 bytes. This is an additional bounded capture, not evidence already in the saved attempt.

## Smallest maintained route

Reuse the accepted carrier's source preparation, four-token split, native SDPA mask and position checks; reuse the older-split cache span operation and finally crop/restore. The six-token `recurrence_key_phase_feedback.py` demonstrates module hook order but is tied to its old globals, so a later producer would adapt only its local capture/actuate/observe pattern. For each base, capture Q/K/V from its **unpatched native anchor**. During a suffix call, install target-only replacement hooks on `q_norm`, `k_norm`, `v_proj` **before** observation hooks, preserving companions and matching output dtype/device; remove hooks in `finally`. Put hook lifetime and suffix forward inside the existing `torch.inference_mode()` cache scope, then crop and restore both older axes and full cache digest even on a raised body exception. Do not replace residual streams, MLP outputs, attention head outputs, historical or latest cache, phase, tokens, masks, positions, or companions.

Installed `Qwen3VLTextAttention.forward` consumes normalized Q/K before RoPE, appends rotated K and projected V through `past_key_values.update`, then calls SDPA. Proposed all-layer proof is: observed post-hook target Q/K/V equal the same-base native capture; observed companions equal their unhooked values; observed rotary positions and mask equal source; appended header K equals rotated captured K, appended V equals captured V; post-RoPE captured Q plus actual full K/V and native mask reconstructs the `o_proj` input within a separately frozen technical tolerance. This last check tests the actual attention read rather than treating a module hook as proof of consumption. All historical prompt/older/latest spans must match their declared corner at attention entry and after suffix; companion K/V, logits and input/position hashes must match the base anchor. No full-cache dump is needed.

CPU preflight for any later admission should exercise this **actual caller and serialized receipt**, rejecting wrong target, base donor, layer count, one dropped header position, Q-only clamp, altered companion, older-axis crossover, wrong rotary/mask/cache slot, and changed source input. Fixture should prove native captures and clamped outputs for all three axes and four positions, hook order, wrong-shape rejection, and exception-path cache crop/older restoration/hook removal. Cold readback in a separate process must rehash direct imports, source, per-cell inputs/vectors/captures/consumer records and recompute all-four full-vector reference and companion comparisons. A technical gate failure stops before dependent treatments; a scientific nonpass would not skip the other fixed components. The lead must freeze technical tolerances and scientific criteria in any later admission; the previous `2e-4` full/cache tolerance and old `2e-5` appended-K check are precedents, not new science thresholds.

## Finite proposal and measured-shape forecast

Proposed order: fresh AF/FF full references (2 model/2 vision), AF/FF prefills (2/2), AF/FF native anchors with captures (2/0), AF/FF older-write shams (2/0), both joint older K/V swaps (2/0), both V-only and both K-only swaps (4/0), then AF/FF **separately executed native Q/K/V clamp identities** (2/0), then AF/FF clamped joint, V-only, K-only corners (6/0). Total **22 model, 4 vision, 0 generated**; first 14 qualify the adaptive factorial against the accepted vectors, and the two clamped identities must pass all-four-vector anchor parity before six clamped treatments. The joint corners remain in both bases; no arm is inferred from another. Saved adaptive vectors are references, not substitutes for new calls when capturing the native tensors.

The accepted 14-call job measured 116.233683 parent outer seconds, 45,230,791 raw bytes, 12,476,571,136 peak allocated GPU bytes, 13,254,000,640 reserved bytes, and 11,093,772 KiB peak RSS. Same `[4,1384]` full, `[4,1380]` prefill, `[4,4]` suffix and `[4,1,4,1384]` mask; source media has 24,502,272 pixel elements. A conservative call-scaled nominal outer estimate is 182.653 s and a 2× planning forecast is **365.306 s**; it includes repeated full/prefill work although the eight new calls are cached suffixes. Eight suffix cells at the measured 2,549,705-byte mean plus the two-base capture give about 69.30 MB raw total; 2× envelope **138.60 MB (132.18 MiB)**, below a prospective 256 MiB evidence envelope. Peak working memory should be rechecked at actual preflight; the small target capture does not justify assuming lower than the measured roughly 12.48 GB allocated/13.25 GB reserved. No elapsed ceiling is proposed. These are a finite cost proposal, **not launch authority**.

The direct source imports, exact command, new producer capture and actual hook implementation do not exist yet; those must be frozen only under a later contract. No model call or new endpoint was made here.
