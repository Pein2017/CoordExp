# Research: start here

This is the agent entry to the registered **research-probes** knowledge base. Research programs live directly under `research/`; there is no new `investigations` classification layer.

## Current program

**[Qwen3-VL dense enumeration](qwen3-vl-dense-enumeration/index.md)** asks how verified object support becomes a complete, non-repeating, naturally greedy set-completion policy through ordinary model parameters.

**Fast catch-up:** [current context](qwen3-vl-dense-enumeration/current.md) → its linked state and accepted result. Recover the current task, evidence boundary and user stop before any action.

**Deep catch-up:** current context → [research story](qwen3-vl-dense-enumeration/story.md) → the relevant question page → decisive original results. The [idea register](qwen3-vl-dense-enumeration/ideas.md) and [experiment catalog](qwen3-vl-dense-enumeration/experiments.jsonl) prevent unfinished alternatives and tested counterexamples from disappearing.

## Existing cross-cutting knowledge

[Ideas](ideas/index.md) retain independent proposed treatments, including dormant denoising and privileged visual-designation work. [Decisions](decisions/index.md) retain evidence-backed research distinctions; dated next-step wording is not a current execution grant. [Mechanisms](mechanisms/index.md) is reserved for genuinely supported reusable explanations, not a place to promote a single suggestive intervention.

[Older curated collections](archive/index.md) and the [frozen source archive](../docs/history/research-records/2026-09-15/README.md) are retrieval paths, not compulsory catch-up. Historical code, reviews, handoffs and the original claim/source ledgers remain attributable. The old `research/investigations` path is only an explicit compatibility alias for preserved references and actual data consumers.

## Before maintaining this tree

Read [CONVENTIONS.md](CONVENTIONS.md). Protocol, current state, accepted evidence, interpretation and transport have distinct owners. Update the surface whose meaning changed; do not copy a full result or append every run to every summary. New proposals must identify their nearest tested predecessor and the exact remaining question.

Current user instructions and fresh registered Project/runtime facts govern action. A record, catalog entry, historical `running` field or old compute grant is not permission to resume. Runtime/product contracts remain in `docs/` and `openspec/`; model artifacts stay in the declared `outputs/research/` root.
