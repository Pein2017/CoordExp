## Pre-execution scientific review

An independent Fable-5/xhigh design audit accepted image `2299` only as a
separately reported prospective slice. It identified four conclusion-critical
constraints that were incorporated before the full owner-accessibility shard:

1. keep the legacy twelve-image denominators unchanged;
2. bind the refined `46 = 38 person + 8 tie` authority row and reject the
   official 22-object row for this unit;
3. make native-TP due-boundary support a validity-bearing transfer gate with a
   frozen `80%` floor; and
4. use root context only for the input-position screen because `(y1, x1)`
   sorted output order confounds post-root row index with image position.

The same review classified image `2299` as a large-owner, heavily crowded,
single-image stress test rather than an iid prevalence sample. It explicitly
closed full-canvas densification, neutral-row insertion, threshold retuning,
and discovery-rule authoring for this unit.

1. **Valid legacy result:** `114/202` eligible native misses retain tested

   transfer-validity floor is not met (`14/19 < 0.8`); all `27` FN

This reconciliation preserves the user's intuitive comparison without
turning a failed measuring instrument into a formal prevalence estimate.
