## Arms

### C: censored transcript CE

For each scheduled image presentation, C teacher-forces the complete observed
processed-row transcript and masks only its annotation-boundary terminal EOS.
It uses ordinary segment-balanced supervised CE.  One image is one physical
pack; cross-image sequence packing is disabled for this experiment.

### D0: fixed-Source actual-prefix positive learning

D0 uses Source-natural prefixes and the existing grouped complete-row loss:

\[
\Phi_\tau(A_e\mid h_e)
=-\tau\log\left[|A_e|^{-1}\sum_{a\in A_e}
  \exp(-\ell(a\mid h_e)/\tau)\right],
\]

with `tau = 0.25`.  It adds the existing mean Source-row preservation term with
weight `1.0`; structural/repetition weight is `0.0`.  Every candidate is a
complete category-and-four-coordinate row.  No coordinate-wise
multiple-positive target is allowed.

The existing rollout-site token-type legality gate remains active at weight
`0.1`; C has no corresponding auxiliary term.  Therefore this pilot estimates
the bundled D0 objective, including that gate, rather than a causal effect of
actual-prefix conditioning alone.

This first direct test uses one immutable Source bank for the full run.  There
is no step-16 refresh, optimizer resume, online rollout, scalar dual, or
checkpoint selection.  A stale-prefix ceiling is an alternative explanation
of a negative result, not a reason to add machinery before this test.

## Matched exposure and DDP topology

Let `B` be the number of newly rebuilt positive plus preservation events and
let global effective batch be `E = 64`.  Before any optimizer step, freeze:

\[
S=\lceil B/E\rceil,\qquad P=ES-B,
\]

where `S` is the update count and `0 <= P < 64`.  The dose bank contains every
base event once, then `P` deterministic SHA-256-seed-ordered repeats with new
event IDs and explicit `source_event_id` provenance.  No base event is dropped.

The C JSONL contains one uniquely identified transcript presentation for every
event in that dose bank, using the same image ID.  Thus C and D0 have the same
per-image presentation multiset, total image forwards, optimizer updates, and
effective batch; synchronized within-step ordering is not required.  Report
the different supervised-token and objective-family counts rather than
claiming equal information content.

Production topology is eight data-parallel ranks, physical batch one image per
rank, gradient accumulation eight, effective batch 64, BF16 training, AdamW,
learning rate `1e-5`, max gradient norm `1.0`, and one frozen runtime seed.
The existing global eligible-event denominator is required; rank-local means
are forbidden.

## Evaluation and decision

Fresh processes dynamically load Source, C, and D0 as base plus unmerged
adapter plus frozen selected-token delta.  Evaluate the same frozen 128-image
screen-dev JSONL under the original prompt, RP `1.0`, temperature `0`, and
natural greedy decoding.  Use strict category-compatible global one-to-one
matching.  IoU50 owns the decision; IoU60 and IoU80 are reported.

For the 891-owner frozen screen ledger, `0.5` percentage point requires at
least five net D0-over-C owner matches.  The single-seed pilot returns:

- `GO_PAIRED_REPLICATION` if D0 has at least five net IoU50 owner gains over C,
  retains at least `98.5%` of Source-covered owners, loses no more
  Source-covered owners than C, and does not exceed twice C's cap/nontermination
  count;
- otherwise `SCIENTIFIC_STOP_DIRECT_C_D0`.

Report exact `0->1` gains, `1->0` losses, retained owner IDs, owner-micro and
image-macro recall at IoU50/60/80, paired image-bootstrap intervals,
unmatched-row burden, length, malformed/invalid/parser outcomes, natural order
violations, EOS/cap bins, wall time, forwards, backwards, collectives, peak GPU
memory, host RSS, workers, cache bytes, and adapter bytes.  Bootstrap and any
matched-swap/permutation diagnostic are descriptive; neither can block launch
or rescue the point-estimate verdict.

A one-seed `GO_PAIRED_REPLICATION` is kill-or-advance evidence only.  It is not
an algorithm-level positive claim, architecture promotion, production
