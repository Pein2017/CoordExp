## Qualification boundary

A's event provides qualified causal evidence for a static query-to-image
routing handle. Dynamic terminal/history muting was behaviorally idle in the
same event, and the fixed crossover interaction was zero. The gradient audit
shows teacher-forced reachability, not rollout improvement; background/control
gradients and the absence of an independent uncovered-owner bank limit owner
specificity.

S contributes H0, support, cohort, and observational evidence, but no causal
P1--P4 result because both attempts failed before the actuator. This is a
technical HOLD, not a zero effect. Raw S-versus-A differences cannot be
attributed to `<|commit|>`, InfoNCE, A3 owner binding, or any single training
change.

## Decision

Close this unit with no architecture or training promotion. Reject a dynamic
commit/history carrier objective as the next family on the present evidence.
If a later user decision authorizes a pilot, prefer a bounded static
owner-localized/query-key routing or region-contrastive objective with explicit
background, covered-owner, same-class, and non-target controls. A matched
attribution control and an independent owner-specificity bank remain required
before causal attribution or scale-up.
