# 空间范围与历史上下文解耦的独立审计

## 术语与名称登记表

本登记表覆盖本审查使用的缩写、实验组代码、假设标识符、指标符号、配置令牌和新造术语。登记一个名称不表示接受该名称暗含的因果解释。

### 严重程度与裁决术语

| 名称 | 完整含义与操作定义 |
|---|---|
| 严重（**P0**） | 执行或解释会从根本上失效。本审查只在已有门禁无法阻止核心结果失真时使用该等级。 |
| 高（**P1**） | 研究单元进入 ready 状态前必须解决，或者受影响结果在解决前不可解释。 |
| 中（**P2**） | 重要的歧义、统计范围或复现性弱点，但不一定阻止主机械检查启动。 |
| 低（**P3**） | 主要涉及清晰度、可维护性或表达质量。 |
| **P1-1**、**P1-2**、**P1-3**、**P1-4**、**P1-5**、**P1-6**、**P1-7**、**P1-8**；**P2-1**、**P2-2**、**P2-3**、**P2-4**、**P2-5**、**P2-6** | “严重程度—该等级内序号”格式的发现唯一标识；前八项是高严重程度发现，后六项是中严重程度发现。编号只用于追踪，不表示发现之间的因果或优先依赖。 |

| 等效 | 配对效应的完整不确定区间落在预先声明的实际可忽略区间内；差异不显著本身不构成等效。 |
| 未决 | 数据既不满足优效，也不满足等效；不得把低统计功效写成“相同”。 |
| 非劣效安全门 | 某实验组在目标挽救增加时，保留率、精确率、有效输出、重复和自然闭合没有超过预先允许的退化幅度。 |

### 模型、数据、对象与协议术语

| 名称 | 完整含义与操作定义 |
|---|---|
| Qwen3 视觉语言模型（**Qwen3-VL**） | 本单元所审查的预训练多模态模型家族及其冻结适配检查点。 |
| Common Objects in Context 80 类本体（**COCO-80**） | 本单元允许报告的 80 个对象类别闭集。闭集外可见对象是“评估范围外对象”，不等于背景或幻觉。 |
| Weight-Decomposed Low-Rank Adaptation（**DoRA**） | 冻结检查点使用的权重分解低秩适配方法。 |
| 交叉熵（**CE**） | 普通下一令牌负对数似然训练目标。 |
| **带有有序累积分布惩罚的高斯软目标坐标交叉熵** | 高斯软坐标目标交叉熵加有序坐标箱累积分布平方差惩罚。历史路径令牌 **gaussian_rps** 只保留来源追踪，不是规范研究术语。 |
| 边界框（**bbox**） | 一个对象的四坐标矩形定位。 |
| 边界框交并比（**IoU**） | 预测框和参考框交集面积除以并集面积。 |
| Validation-200（**val200**） | 现有推理产物使用的固定 200 图像验证范围；在本单元冻结精确图像标识前，它只是规划和基线检查范围。 |
| K 次空间调用（**K**） | 选定网格的单元数；四乘四网格对应 16 次调用。 |
| 实验组（**A**） | 一个完整解析的输入、历史、解码、调用预算和聚合组合。 |
| 参考对象（**o**） | 官方标注账本或审计增强账本中的一个可报告实例。 |
| 经验概率（**P**） | 配对对象上的观测条件比例，不假定参数概率模型。 |
| 核心区域 | 半开空间单元；预测框中心落入该单元时，由该单元唯一拥有预测。 |
| 光环区域 | 核心周围的裁剪上下文，只提供识别像素，不拥有预测。 |
| 每区域重置 | 每次空间调用从同一个新鲜基础提示开始，不带先前接受的对象行。 |
| 累计历史 | 后续调用的提示包含先前接受的对象行。当前单元尚未完整定义“接受”和序列化，属于 P1 发现。 |
| 独立装袋 | 同一全图和基础提示在预声明的不同伪随机种子下进行多次真实随机采样，再执行一个确定性对象集合合并。 |
| 种子向量 | 预先冻结的伪随机种子列表。空间调用把种子绑定到规范网格单元身份，而不是遍历位置。 |
| 调用次数匹配 | 实验组具有相同调用次数、每调用生成上限和种子集合；不表示每对象机会数相等，也不表示总计算量相等。 |
| 跨视图前缀—图像不一致 | 累计提示中的旧对象行来自先前区域，但当前调用图像只显示另一个区域，导致文字历史描述当前视觉输入中不可见对象。 |
| 掩膜空间调度总效应 | 像素掩膜、可见区域、掩膜边界、视觉塔激活变化和每格强制访问共同产生的处理效应；不等于解码器内部候选竞争。 |
| 累计已接受行提示总效应 | 加入特定已接受行提示后，长度、内容、错误、顺序、重复惩罚和跨视图一致性共同产生的总效应；不等于纯历史长度效应。 |
| 同特征视觉后处理干预 | 只对同一次未修改全图编码得到的固定视觉特征改变下游可消费区域，同时保持特征值、令牌身份、位置和数量不变。 |
| 官方标注账本 | 原始 COCO-80 实例标注，保留来源、对象标识和 crowd 等原始字段。 |
| 审计增强账本 | 官方账本加上在执行前、完全不看模型输出时由盲化人工流程新增和裁决的对象。 |
| JavaScript Object Notation（**JSON**） | 清单和回执使用的结构化序列化格式。 |
| JavaScript Object Notation Lines（**JSONL**） | 每行一个独立 JSON 记录的格式，用于样本和逐调用产物。 |
| Secure Hash Algorithm 256 bit（**SHA-256**） | 用于冻结文件、配置、模型和产物字节身份的 256 位内容摘要。 |
| OpenSpec | 仓库中管理稳定、可复用实现或兼容性契约的工作流；不得承载研究假设、样本队列或科学裁决。 |

### 实验组代码

| 完整名称与代码 | 可执行操作含义 |
|---|---|
| 全图像单次生成（**FULL_SINGLE**） | 在解析后的单元解码策略下，对完整图像执行一次生成。 |
| 全图像 K 次独立生成装袋（**FULL_BAG_K**） | 对完整图像按 K 个预声明种子执行 K 次真实随机采样，再用冻结对象合并器聚合。 |
| 原生尺度分块逐块重置（**TILE_RESET**） | 对不缩放的核心加光环分块逐块解码，每块使用新鲜提示。 |
| 原生尺度分块累计历史（**TILE_CUMULATIVE**） | 使用同一分块输入，但把先前接受行加入后续提示。 |
| 全画布掩膜区域逐区域重置（**MASK_RESET**） | 保持完整画布尺寸，每次只暴露一个核心加光环区域，并使用新鲜提示。 |
| 全画布掩膜区域累计历史（**MASK_CUMULATIVE**） | 使用相同掩膜画布，但把先前接受行加入后续提示。 |
| 全画布掩膜仅核心重置（**MASK_RESET_CORE_ONLY**） | 与 MASK_RESET 相同，但不暴露光环区域。 |
| 全画布掩膜累计历史置换顺序（**MASK_CUMULATIVE_PERMUTED**） | 与 MASK_CUMULATIVE 相同，但按一个预声明的非栅格顺序访问单元。 |

### 假设、协议不变量与指标代码

| 名称与代码 | 可执行操作含义 |
|---|---|
| 空间范围竞争（**HYPOTHESIS_SPATIAL_SCOPE**） | 同时存在的对象候选压低局部有效后续路径。当前像素掩膜只能测试输入级空间限制策略，不能定位该内部机制。 |
| 历史跨度不稳定（**HYPOTHESIS_HISTORY_HORIZON**） | 更长的自回归前缀使后续对象检索或继续生成变差。只有固定视觉输入并析因控制前缀长度、内容和错误后才能直接测试。 |
| 分块局部计算解释（**HYPOTHESIS_TILE_LOCAL_COMPUTATION**） | 原生分块可能因视觉令牌更少、局部坐标或位置框架、填充、上下文删除或局部重编码而变化。它是残余机制族，不是一个已隔离机制。 |
| 分区与边界上下文（**HYPOTHESIS_CONTEXT_BOUNDARY**） | 对象被切割或缺少周围上下文导致边界附近性能变化。 |
| 几何排序遍历先验（**HYPOTHESIS_GEOMETRY_ORDER**） | 栅格访问与几何排序训练行的顺序先验一致，因此累计条件可能受益。 |
| 密集场景标注缺口（**HYPOTHESIS_ANNOTATION_GAPS**） | 某些未匹配预测是真实但未被官方标注的 COCO-80 实例。 |
| 剩余识别或控制状态限制（**HYPOTHESIS_RESIDUAL_LIMIT**） | 所有处理仍未挽救的对象可能受识别能力或对象特异控制限制；当前单元不能区分二者。 |
| 不缩放尺度不变量（**INVARIANT_NO_RESIZE_SCALE**） | 每个输入必须保持对象原始像素尺度。它不声称视觉令牌数、位置编码或视觉表示相同。 |
| 局部挽救率（**LRR**） | 在配对 FULL_SINGLE 未检测到的参考对象中，实验组最终检测到的比例。 |
| 保留率（**Retention**） | 在配对 FULL_SINGLE 已检测到的参考对象中，实验组仍检测到的比例。 |
| 平均精确率（**AP**） | 在完整命名的评分与评估规则下，由精确率—召回率曲线汇总的检测指标。 |
| 平均平均精确率（**mAP**） | 官方 COCO 边界框评估在交并比 0.50 到 0.95 阈值上平均的 AP。 |
| **mAP_50** 与 **mAP_75** | 分别在交并比 0.50 与 0.75 下的官方平均精确率。 |
| 平均召回率（**mRecall**） | 官方 COCO 评估中的平均召回汇总，必须连同最大检测数等评估配置命名。 |
| **Local_Rescue_Rate_A** | 实验组 A 的局部挽救率序列化键。 |
| **Retention_A** | 实验组 A 的保留率序列化键。 |
| **Spatial_Scope_Effect** | 当前单元对 LRR(MASK_RESET) 减 LRR(FULL_BAG_K) 的名称。本审查要求改为“掩膜重置相对 K 次全图装袋挽救差”。 |
| **Masked_History_Effect** | 当前单元对 LRR(MASK_RESET) 减 LRR(MASK_CUMULATIVE) 的名称。本审查要求改为“掩膜重置相对累计已接受行提示挽救差”。 |
| **Tile_History_Effect** | 当前单元对 LRR(TILE_RESET) 减 LRR(TILE_CUMULATIVE) 的名称。本审查要求改为“分块重置相对累计已接受行提示挽救差”。 |
| **Local_Frame_Effect** | 当前单元对 LRR(TILE_RESET) 减 LRR(MASK_RESET) 的名称。本审查要求改为“原生分块相对掩膜画布挽救差”，因为视觉令牌、坐标框架、填充和编码均改变。 |
| 图像聚类自举置信区间 | 重采样整张图像，并把该图像的所有对象和配对实验组结果一起保留后计算的不确定区间。 |
| 重复预测组件 | 按冻结的同类与重叠边规则连接形成的预测连通分量；边规则和阈值必须在执行前确定。 |
| 自然闭合 | 模型按冻结终止令牌正常结束，而不是达到生成上限、控制器上限、错误或强制截断。 |

| **sanity check**、**deterministic fixture**、**tiny mechanics gate** | 分别表示只排除明显错误的轻量合理性检查、输入输出完全固定的确定性测试样例，以及在全量运行前验证像素、提示、随机流、坐标、所有权和产物模式的极小机械门禁；三者都不构成模型效果证据。 |
| **patch**、**padding**、**batch size** | 分别表示视觉编码器的图像小块、为满足形状或对齐而增加的填充，以及一次并行处理的请求数；这些量必须在跨实验组机械对比中记录。 |

#### P2-2：一个固定置换只能测一个具体顺序

- **类别：科学设计。**

- **最强竞争解释：** 早晚单元的对象密度或难度、提示长度和历史错误。
- **最小修正：** 使用跨图像平衡的多个预注册置换，并增加重置置换机械负对照；归因训练先验仍需不同训练顺序检查点。
- **阻塞范围：** HYPOTHESIS_GEOMETRY_ORDER 的解释，不阻塞主五组面板。

#### P2-3：一个冻结种子向量只能支持种子条件结论

- **类别：统计范围。**

- **最强竞争解释：** 特定种子集合与实验组或空间单元偶然交互。
- **最小修正：** 明确主结论条件于冻结种子向量；用图像标识、实验组、单元和调用身份确定性派生种子，并在机制晋升前用独立根种子复制。

#### P2-4：统计单位和次要分析仍需冻结

## 逐假设审计

### 空间范围竞争（HYPOTHESIS_SPATIAL_SCOPE）

- **研究动机：** 密集全图在每个行边界呈现许多可行对象，局部限制可能提高某个遗漏对象的继续路径。
- **可以被识别的机制：** 修正后只能识别掩膜空间调度相对 K 次全图采样的策略总效应。
- **最强竞争解释：** 掩膜指示、视觉塔分布变化、背景删除、全局上下文删除和外部网格覆盖配额。
- **可检验预测：** MASK_RESET 在 post-merge LRR 和 raw owning-cell 检测上优于 FULL_BAG_K，并通过保留率、人工精确率、重复、有效性和闭合安全门。
- **证伪条件：** 在机械检查、等效精度和 raw 机会分解充分时，选定掩膜策略没有实际相关收益；这只否定该干预句柄，不否定一切候选竞争。
- **剩余混淆因素：** 空间限制发生在视觉编码之前。
- **允许提出的结论：** 对此检查点、队列、网格、掩膜和解码策略，输入级空间调度有用、无用或未决。禁止定位为视觉塔之后。

### 历史跨度不稳定（HYPOTHESIS_HISTORY_HORIZON）

- **研究动机：** 更长的自生成前缀可能累积错误、重复结构和列表长度先验。
- **可以被识别的机制：** 当前两组只能识别累计已接受行提示总效应；固定视觉输入和前缀析因后才能识别长度成分。
- **最强竞争解释：** 跨视图不一致、坏历史、丢失有用覆盖信息、顺序、坐标系冲突和提示包含式重复惩罚。
- **可检验预测：** repetition_penalty=1.0 时，重置在掩膜与分块族中均优于累计；长度匹配中性前缀复制出长度成分，而错误历史产生额外损害。
- **证伪条件：** 在干净、错误和长度匹配前缀以及固定视觉输入下，较长干净历史没有实际相关退化。
- **剩余混淆因素：** 前缀长度、内容和位置很难在自然生成中完全独立。
- **允许提出的结论：** 冻结累计提示策略相对重置有益、有害或等效。禁止写成纯记忆容量根因。

### 分块局部计算解释（HYPOTHESIS_TILE_LOCAL_COMPUTATION）

- **研究动机：** 不缩放分块仍可能因更少视觉令牌或局部视觉编码而改善。
- **可以被识别的机制：** TILE_RESET 相对 MASK_RESET 的复合分块处理差。
- **最强竞争解释：** 令牌数量、局部位置框架、填充、patch 对齐、上下文删除和重编码中的任一项。
- **可检验预测：** TILE_RESET 优于 MASK_RESET，而 MASK_RESET 接近 FULL_BAG_K。
- **证伪条件：** MASK_RESET 在等视觉令牌画布条件下已有稳定收益会削弱“只有原生分块才有用”，但不能逐项排除分块机制族。
- **剩余混淆因素：** 当前没有正交视觉析因。
- **允许提出的结论：** 原生分块复合处理相对掩膜画布有用或无增益；禁止指定单一视觉侧原因。

### 分区与边界上下文（HYPOTHESIS_CONTEXT_BOUNDARY）

- **研究动机：** 核心边界会切割对象或移除识别上下文。
- **可以被识别的机制：** MASK_RESET 相对 MASK_RESET_CORE_ONLY 的掩膜光环总效应，以及效应随对象到边界距离的变化。
- **最强竞争解释：** 光环扩大了可见面积和候选对象数，而不是修复边界上下文。
- **可检验预测：** 光环收益集中在边界附近，且不伴随广泛重复或范围外预测增加。
- **证伪条件：** 有足够精度时，边界附近没有收益或只出现重复增长。
- **剩余混淆因素：** 当前没有原生分块仅核心实验组，因此不能直接定位硬分块切割。
- **允许提出的结论：** 光环对掩膜画布的边界附近策略有效或无效；禁止推广为原生分块边界机制。

### 几何排序遍历先验（HYPOTHESIS_GEOMETRY_ORDER）

- **研究动机：** 适配器以几何排序行训练，栅格空间访问可能与该先验一致。
- **可以被识别的机制：** 当前最多识别一个具体非栅格顺序相对规范顺序的总顺序敏感性。
- **最强竞争解释：** 单元难度乘序列位置、提示长度、历史错误和空间邻接。
- **可检验预测：** 多个跨图像平衡置换对累计组有一致影响，而重置置换机械负对照不受影响。
- **证伪条件：** 在多个平衡顺序和足够精度下没有实际相关顺序效应；这仍不等于随机顺序训练模型无先验。
- **剩余混淆因素：** 只有一种几何排序训练检查点。
- **允许提出的结论：** 当前检查点对所测试顺序敏感或不敏感。归因训练先验需要不同训练顺序检查点。

### 密集场景标注缺口（HYPOTHESIS_ANNOTATION_GAPS）

- **研究动机：** 官方 COCO 在密集场景可能漏掉真实实例。
- **可以被识别的机制：** 在执行前冻结的图像级穷尽 COCO-80 账本上，官方未匹配预测中有多少是被独立人工接受的实例。
- **最强竞争解释：** 模型幻觉、重复、范围外对象、crowd、部分可见歧义或预测驱动的人工确认偏差。
- **可检验预测：** 官方精确率下降而预先冻结审计账本上的人工精确率和唯一召回保持或上升，且审查者一致性可接受。
- **证伪条件：** 盲化审计也把新增预测判为无支撑，或人工精确率与官方精确率一起下降。
- **剩余混淆因素：** 人工可见性和实例边界本身存在判断误差。
- **允许提出的结论：** 在冻结人工子集和 COCO-80 本体内，某比例官方未匹配预测属于标注缺口。禁止推广为大多数全数据误报。

### 剩余识别或控制状态限制（HYPOTHESIS_RESIDUAL_LIMIT）

- **研究动机：** 某些可见对象可能在所有范围、历史和采样处理下持续遗漏。
- **可以被识别的机制：** 只能形成“当前干预族未挽救的对象集合”。
- **最强竞争解释：** 解析、类别、评分、种子、输出上限、干预未触达、审计错误或共同视觉分布问题。
- **可检验预测：** 同一人工可见对象在 FULL_BAG_K、TILE_RESET 和 MASK_RESET 中持续遗漏。
- **证伪条件：** 某个结构化处理可靠挽救该对象，只削弱它属于当前残余集合。
- **剩余混淆因素：** 识别能力和对象特异控制完全未分离。
- **允许提出的结论：** 对当前处理族存在持久遗漏集合。禁止把它命名为纯识别失败或纯控制状态失败。

### 不缩放尺度不变量（INVARIANT_NO_RESIZE_SCALE）

- **研究动机：** 排除对象像素放大这一显然混淆。
- **可以被识别的机制：** 这不是机制，而是必须通过回执证明的协议条件。
- **最强竞争解释：** 处理器静默缩放、填充或 patch 对齐改变有效像素。
- **可检验预测：** 每个实验组的原始对象像素尺寸保持不变，do_resize=false，坐标往返通过。
- **证伪条件：** 任一静默缩放立即使运行无效。
- **剩余混淆因素：** 视觉令牌数、位置编码、坐标框架和视觉表示仍可不同。
- **允许提出的结论：** 对象像素尺度被控制；不得说视觉侧整体被控制。

### 匹配语义

当前 class 相同、IoU 至少 0.50、先最大匹配数再最大总 IoU 的一对一匹配骨架是可接受的。执行前仍需冻结：

1. 预测与参考对象的不可变索引；
2. 同匹配数且同总 IoU 时的词典序匹配分配平局裁决；
3. 浮点容差、坐标裁剪、无效框和边界框面积规则；
4. 官方类别规范化与研究别名表的分离；
5. 0.50 为主、0.75 为预声明敏感性，不得按结果挑选。

### 局部挽救率与保留率

对每一本命名账本，post-merge 主指标应严格为：

- LRR 分子：FULL_SINGLE 未匹配而实验组 A 匹配的参考对象数；
- LRR 分母：FULL_SINGLE 未匹配的参考对象总数；
- Retention 分子：FULL_SINGLE 与 A 都匹配的参考对象数；
- Retention 分母：FULL_SINGLE 已匹配的参考对象总数；
- 条件分母为空时返回 not applicable，并保留分子和分母。

post-merge LRR 适合评价最终策略，但不足以解释机制。必须同时保留：

- 每对象拥有单元 raw 检测；
- K 次调用中任一次 raw 检测；
- pre-merge 到 post-merge 的匹配创建、保留与丢失；
- 每调用增量唯一召回。

### 精确率、重复预测与无效行

- 人工精确率分母应为所有最终有效 post-merge 预测；同类重复、范围内错误对象和未匹配预测均是未命中，不能被合并后静默消失而不留诊断。
- 一对一匹配保证重复不能提高召回，但 pre-merge 重复仍须进入重复组件、计算成本和安全门。
- 重复组件必须冻结同类规则、IoU 边阈值和连通分量算法。
- 无效或畸形跨度不得匹配；同时分别报告每尝试调用无效率、每尝试对象跨度无效率、部分 salvage 和达到 max_new_tokens 的长度终止。
- 自然闭合必须区分正常 STOP、长度上限、控制器上限、错误和强制截断。
- 预测数量只能作为诊断，不得替代唯一召回、精确率、保留率和闭合。

### 官方标注账本与审计增强账本

- 官方指标只使用官方账本和官方类别、坐标、crowd 与评分语义。
- 审计增强指标只使用执行前冻结的审计账本。
- 执行后由未匹配预测触发的人工裁决必须进入另一份明确命名的次要账本，不能回写主审计账本。
- 每项指标名称必须显式包含 Official-Annotation 或 Audit-Augmented，禁止无标签池化。

### AP 与评分

官方 mAP、mAP_50、mAP_75 和 mRecall 只能消费具有有限对象分数、对象级 pred_score_source、版本和评分策略摘要的 scored artifact。K 次调用合并前必须规定：

- 每个预测保留哪个原始调用和对象跨度的令牌追踪；
- 抑制预测的来源如何保留；
- 融合框是否允许；若允许，融合分数和父预测必须可重放；
- 排序分数是原始选择令牌分数、最大值、平均值还是另一冻结函数；
- 人工固定阈值指标与官方排序 AP 不混用。

### 不确定性估计

- 图像聚类是正确的基本依赖单位；同一自举复制必须保留一张图像的全部对象、全部实验组和全部调用。
- 主区间必须说明是对冻结图像样本、条件于冻结种子向量的推断。
- 分层抽样时按分层重采样或明确不外推到 val200 总体。
- 冻结 percentile、basic 或 bias-corrected and accelerated 中的一种区间算法，并规定空分母复制。
- 对象微平均为主时增加图像宏平均敏感性，避免少数极密集图像支配。

| 所有实验组遗漏同一对象 | 当前干预族未挽救这些对象 | 范围和累计提示是充分解决方案 | 视觉不可见、类别或解析问题、对象控制不足 | 存在当前处理族的持久遗漏集合 | 同全图固定特征上的目标特异因果读写实验 |

## 实际未被检验的假设

| 必须挑战的假设 | 当前状态 | 审计结论 |
|---|---|---|
| 1. 局部条件产生更多预测，说明完整图像条件已经识别这些目标 | **未解决** | 干预后能输出只证明干预表面上的可解码性，不证明原全图自然生成已形成或使用对象表示。 |
| 2. 掩膜只改变解码器内部候选竞争 | **未解决** | 掩膜明确改变视觉塔输入、下游激活和外生覆盖计划。 |
| 3. 未缩放就意味着视觉侧表示受控 | **部分检验** | 只控制对象像素尺度；令牌数、位置、坐标框架、填充、上下文和编码未控制。 |
| 4. 重置与累计之间只隔离历史长度 | **部分检验** | 只比较累计已接受行提示总效应，仍混合内容、错误、顺序、跨视图不一致和重复惩罚。 |
| 5. 预测数量增加意味着枚举质量提高 | **部分检验** | 已计划 LRR、保留率、精确率、重复、无效和闭合，但尚无联合安全裁决规则。 |
| 6. 相对官方标注的误报大多是漏标目标 | **部分检验** | 预冻结人工子集可以检验局部比例；当前人工模式不完整，且不能支持“大多”或全数据外推。 |
| 7. 几何位置排序只是表面现象 | **部分检验** | 一个置换只能检测具体顺序敏感性，不能定位训练先验。 |
| 8. 正向结果意味着必须引入账本或持久状态 | **未解决且明确禁止推断** | 当前没有账本或状态干预；所有结果都必须保持 not_promoted。 |
| 9. 调用次数相同意味着计算量相同 | **作为协议不变量已完整否定** | 单元正确声明 matched-call 不等于 matched-compute；执行仍须报告提示、图像、生成令牌、调用和时间预算。 |
| 10. 信息可被解码意味着生成时因果使用该信息 | **未解决** | 历史特权视觉指示只证明受控表面可驱动输出；目标特异来源替换与空对照才可证明因果消费。 |

此外，当前单元范围外的假设包括：

- 同一全图视觉特征上的空间后处理能否复制像素掩膜收益；
- 纯前缀长度、纯历史错误和纯列表位置各自的效应；
- 随机顺序训练检查点是否消除几何顺序敏感性；
- 其他检查点、模型规模、温度、重复惩罚、网格和开放世界本体上的泛化；
- 可读对象表示是否在自然生成中被目标特异地写入、消费并转化为下一对象；
- 显式账本、槽位、游标、提议头或最终架构是否必要；
- 训练能否改善密集枚举并同时保护原生能力。

## 可复用研究工作流建议

1. **把策略总效应与内部机制定位分开。** 像素掩膜、分块和提示调度可以先证明策略效用；机制定位需要同特征、来源替换或消融。
2. **区分调用次数、每对象机会和计算量。** 三者分别记录，不能互相代替。
3. **累计生成必须有显式状态机。** 接纳、序列化、坐标、清洗、错误、闭合和上下文溢出都应成为回执字段。
4. **最终策略指标与机制诊断同时保留。** post-merge LRR 回答策略价值，raw owning-cell 和 pre-to-post 变化回答机会与聚合来源。
5. **部分标注数据使用两阶段但不回写的账本。** 执行前图像穷尽账本是主参考；执行后预测触发裁决只能是另一个次要敏感性账本。
6. **正向枚举结果必须有安全门。** 唯一召回、保留率、精确率、重复、无效输出、预测数量和自然闭合共同决定，不使用单一预测数。
7. **路径是定位句柄，不是证据。** 接受证据需要 authored/resolved 配置、内容摘要、执行回执、失败、原始 metric primitives 和终态。
8. **代码复用服从研究生命周期。** 设计接受后，scripts/research/ 只承载薄命令行、队列和实验组编排、回执写入；src/analysis/ 承载经测试的网格所有权、坐标、合并、匹配、自举和账本验证。

当前没有充分理由创建承载本研究假设的 OpenSpec。若后续只实现单元专用 research-only runner 与分析器，可不创建 OpenSpec；若修改 InferGenerationConfig、DecodeRequest、规范推理后端、助手前缀提示契约、scored artifact 或官方评估合并模式，则必须创建一个范围很窄的 OpenSpec 变更。

## 最终建议

- **是否继续推进：** 是，但仅在上述指定修正完成后；当前不得把状态改为 ready，也不得启动模型执行。
- **首先必须修正什么：** 首先把累计提示对比缩写为总效应并消除 repetition_penalty 与跨视图不一致的解释混淆；同时冻结并实现真实随机 FULL_BAG_K 和累计提示状态机。没有这两个对照，三方主面板不能成立。
- **当前不得构建什么：** 不得构建账本、槽位、对象游标、持久状态、提议头、最终检测架构或面向稳定接口的广泛 OpenSpec。
- **哪些证据足以启动下一研究单元：** 若掩膜重置在安全门下稳定优于 K 次全图装袋，可启动同一次全图视觉编码上的同特征后处理单元；若固定视觉输入的前缀析因确认干净长度效应或错误历史效应，可启动最小短历史或状态压缩单元；若只有原生分块复合处理有益，可启动视觉令牌、位置框架和局部重编码的正交判别单元。任何单一正向结果仍不授权架构晋升。
