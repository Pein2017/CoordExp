# Route, Readout, And Value Flow

Several records separate attention route, value contribution, residual readability, and continuation behavior. A source can receive route mass without helpful value contribution, and a readable direction can fail to survive the continuation path.

Future probes should report route, value, residual readout, and generated continuation together when possible.
