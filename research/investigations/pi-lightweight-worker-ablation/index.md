# Pi Lightweight External Worker Ablation

This investigation tests whether Pi can serve as a minimal-context external
worker for bounded CoordExp tasks while Codex retains research decomposition,
safety, independent verification, and the final verdict.

The investigation is a harness capability and total-cost screen. It does not
authorize CoordExp integration, Codex-core modification, graphics-processing-
unit work, or Pi as a scientific decision maker.
