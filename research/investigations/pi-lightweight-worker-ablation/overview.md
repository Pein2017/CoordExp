# Pi Lightweight External Worker Ablation Overview

## Question

Can a minimal-context Pi worker preserve task correctness and scope compliance
while reducing the complete cost of delegated, mechanically verifiable
CoordExp work after Codex verification and retries are included?

## Current Boundary

- Pi is an external worker harness, not a native Codex Multi-Agent Version 2
  thread.
- Codex owns task decomposition, scientific meaning, safety, hidden checks,
  correction cost, and the final verdict.
- The first screen is read-only and uses frozen copies of closed evidence.
- Pi receives no active-project memory, future Git history, hidden verifier,
  unrelated credentials, graphics-processing-unit access, or writable
  CoordExp checkout.
- A model or reasoning-effort mismatch demotes a comparison to a capability
  scout; it cannot identify a harness effect.

## Adoption Gate

Do not build an adapter or reusable integration from installation or one good
answer. A larger frozen benchmark is justified only if Pi has no critical
scientific, security, or scope failure, passes at least three of four Stage 0
tasks on the first attempt, and retains a material median total token or cost
advantage after independent verification.

If only artifact inventory or deterministic aggregation wins, keep Pi limited
to that task family. Prefer native Codex agents for shared research context,
iterative causal judgment, architecture choice, or final evidence
interpretation.

## Stage 0 Outcome

The port-9090 infrastructure rerun completed all twelve Pi cells. Artifact
inventory and deterministic aggregation pass for Luna, Terra, and Sol. Under
an audited multi-row-aware source-routing verifier, Luna and Terra pass while
Sol repeats the native Sol control's exact symbol-capitalization error. Claim
audit core conclusions are correct, but the original lexical limitations
verifier rejects all three Pi answers.

This clears the capability and observable scope gate for a larger frozen
benchmark of mechanically verifiable tasks. It does not clear the cost gate:
native Codex exposes no comparable token or monetary receipt, and the current
rotated single-cell matrix cannot rank models or reasoning levels causally.
Do not build an adapter or promote Pi to a default route from this unit.
