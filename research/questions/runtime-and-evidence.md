## Evidence semantics

Separate planned protocol, attempted execution, technically valid output, accepted measurement, scientific interpretation and current authorization. A valid empty/dropped output can be a real low score under a declared evaluator, not automatically an invalid run. Conversely, missing required output or a failed null comparison must not be encoded as numeric zero evidence.

A derived-evaluation-only repair can reuse intact raw model output only when the defect did not affect selection, training, rewards, stopping or model execution. Preserve the old invalid evaluation and bind a new evaluator/result identity. Otherwise the affected execution is still unanswered and requires an appropriately authorized new run.

Frozen receipts may bind protocol, code and test bytes as well as checkpoints. Never update those bytes or replace their hashes to make an old run appear accepted. Ordinary archive movement is not original-context replay.
